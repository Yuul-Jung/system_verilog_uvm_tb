제03장 · 반복 자극과 작업 분리

기존 PWM RTL을 사용하여 task·function·repeat·for·wait를 재사용 가능한 검증 절차로 연결

6부 · 24장반복 자극 · 작업 분리기존 RTL 재사용

00개요 · 반복 검증의 구조

제2장에서 PWM 회로의 클록과 리셋, 설정 요청과 반영 시점을 관찰했습니다. 이번 장은 회로를 바꾸지 않고 반복되는 입력 자극을 task로 묶고, function으로 계산하며, 반복문과 상태 대기로 다섯 가지 듀티를 차례로 관찰합니다.

선행 설계 학습안내서: 제2부 사용자 AXI IP와 주변장치(amd_soc_p2), 04.2장 「RTL · AXI 풀이」 02절 「설정 Shadow와 출력 Active를 분리」 및 06절 「독립 PWM Core 전체」. 검증 대상은 pwm_core.v 하나입니다. AXI 래퍼와 보드는 시험하지 않습니다.

01원본 RTL과 검증 계약

제2장과 같은 독립 PWM(Pulse Width Modulation, 펄스폭 변조) 코어를 사용합니다. 아래 전체 코드를 reference_rtl/pwm_core.v에 저장합니다.

reference_rtl/pwm_core.v · Verilog
`timescale 1ns/1ps
// P2-04: 보드와 무관한 단일 채널 범용 PWM 코어.
// (추가) period와 duty는 클록 횟수 단위. 0%/100%는 지속 LOW/HIGH.
// (추가) 설정은 주기 마지막 경계에서만 활성값으로 반영.
module pwm_core #(
    parameter [31:0] RESET_PERIOD = 32'd100000
)(
    input  wire        clk,
    input  wire        resetn,
    input  wire        cfg_apply,
    input  wire [31:0] cfg_period,
    input  wire [31:0] cfg_duty,
    input  wire        cfg_enable,
    input  wire        cfg_polarity,
    output wire        pwm_out,
    output reg         pending,
    output reg [31:0] active_period,
    output reg [31:0] active_duty,
    output reg         active_enable,
    output reg         active_polarity
);
    reg [31:0] counter;
    reg [31:0] shadow_period;
    reg [31:0] shadow_duty;
    reg        shadow_enable;
    reg        shadow_polarity;

    wire boundary = (counter >= active_period - 32'd1);
    wire duty_high = (counter < active_duty);

    // (주의) enable=0이면 polarity와 관계없이 LOW로 차단.
    // (설명) 기본 polarity에서 active_duty=0이면 항상 LOW,
    //         active_duty=active_period이면 항상 HIGH.
    assign pwm_out = resetn && active_enable &&
                     (active_polarity ? !duty_high : duty_high);

    always @(posedge clk) begin
        if (!resetn) begin
            counter         <= 32'd0;
            active_period   <= RESET_PERIOD;
            active_duty     <= 32'd0;
            active_enable   <= 1'b0;
            active_polarity <= 1'b0;
            shadow_period   <= RESET_PERIOD;
            shadow_duty     <= 32'd0;
            shadow_enable   <= 1'b0;
            shadow_polarity <= 1'b0;
            pending         <= 1'b0;
        end else begin
            if (boundary) begin
                counter <= 32'd0;
                if (pending) begin
                    active_period   <= shadow_period;
                    active_duty     <= shadow_duty;
                    active_enable   <= shadow_enable;
                    active_polarity <= shadow_polarity;
                    pending         <= 1'b0;
                end
            end else begin
                counter <= counter + 32'd1;
            end
            // (추가) 경계와 APPLY가 겹치면 새 값은 다음 경계에 적용.
            // 여러 APPLY가 겹치면 최종 요청값을 우선하는 단일 Shadow 구조.
            if (cfg_apply) begin
                shadow_period   <= cfg_period;
                shadow_duty     <= cfg_duty;
                shadow_enable   <= cfg_enable;
                shadow_polarity <= cfg_polarity;
                pending         <= 1'b1;
            end
        end
    end
endmodule

설정 요청 cfg_apply가 상승 에지에서 읽히면 Shadow 값과 pending이 갱신됩니다. 주기 경계에서는 기존 Shadow 값을 Active에 반영합니다. 이번 실습은 주기 8클록, 정상 극성, 활성 출력만 대상으로 합니다. pending이 1이 되었다가 0으로 돌아온 다음부터 새 듀티를 관찰합니다.

신호비트 폭검증 역할
clk, resetn, cfg_apply각 1클록·동기식 내부 리셋·설정 요청
cfg_period, cfg_duty각 32주기 및 HIGH 클록 수
cfg_enable, cfg_polarity각 1출력 허용·극성
pending, pwm_out각 1반영 대기·출력
active_period, active_duty각 32실제로 적용된 값
active_enable, active_polarity각 1현재 허용·극성

02task·function·반복문의 역할

구문역할이번 코드
task(태스크)시간을 소비하는 절차를 묶음request_pwm(), observe_one_period()
function(펑션)시간을 소비하지 않는 값 계산duty_percent()
repeat정해진 횟수만큼 반복리셋 중 하강 에지 두 번
for값을 증가시키며 반복듀티 0, 2, 4, 6, 8 및 8회 표본
wait조건이 참이 될 때까지 대기pending === 1'b1 → 1'b0
automatic호출마다 독립적인 지역 저장 공간두 task와 function

wait(pending === 1'b0)만 쓰면 아직 요청하지 않은 초기 상태에서도 통과합니다. 먼저 요청 수락 상태인 1을 확인한 후 0을 기다립니다. 이 TB에서는 설정을 한 클록 유지하고, 다음 하강 에지에서 해제하므로 현재 DUT의 pending을 안정적으로 관찰할 수 있습니다. 다른 DUT에서는 펄스가 짧거나 적용 시점이 다르면 별도의 모니터가 필요합니다.

duty_percent()는 정수 백분율을 반환합니다. 이번 0·2·4·6·8 / 8에서는 정확히 나누어지지만 임의 듀티에서는 소수점이 버려지며, 범용화 시 0 분모와 곱셈 폭을 확인해야 합니다.

03테스트벤치 전체 코드

전체 코드를 tb/ch03/tb_pwm_reusable_stimulus.sv에 저장합니다. 5개 설정에 동일한 두 작업을 반복 호출합니다.

tb/ch03/tb_pwm_reusable_stimulus.sv · SystemVerilog
`timescale 1ns/1ps
// 제03장: task, function, repeat, for, wait로 PWM 입력 자극을 재사용한다.
// DUT는 기존 pwm_core 원본을 참조하며, 이 TB는 관찰용이다.
// 자동 PASS/FAIL 판정은 제04장에서 다룬다.
module tb_pwm_reusable_stimulus;
    reg         clk;
    reg         resetn;
    reg         cfg_apply;
    reg  [31:0] cfg_period;
    reg  [31:0] cfg_duty;
    reg         cfg_enable;
    reg         cfg_polarity;

    wire        pwm_out;
    wire        pending;
    wire [31:0] active_period;
    wire [31:0] active_duty;
    wire        active_enable;
    wire        active_polarity;

    // 원본 RTL의 포트 13개를 이름 그대로 연결한다.
    // 인스턴스 초기 주기만 8클록으로 축소해 관찰 시간을 절약한다.
    pwm_core #(.RESET_PERIOD(32'd8)) dut (
        .clk             (clk),
        .resetn          (resetn),
        .cfg_apply       (cfg_apply),
        .cfg_period      (cfg_period),
        .cfg_duty        (cfg_duty),
        .cfg_enable      (cfg_enable),
        .cfg_polarity    (cfg_polarity),
        .pwm_out         (pwm_out),
        .pending         (pending),
        .active_period   (active_period),
        .active_duty     (active_duty),
        .active_enable   (active_enable),
        .active_polarity (active_polarity)
    );

    // (추가) 클록 주기: 5ns + 5ns → 10ns.
    initial clk = 1'b0;
    always #5 clk = ~clk;

    // (추가) function은 시뮬레이션 시간을 소비하지 않고 값을 반환한다.
    // 실습 범위는 period=8이므로 나눗셈 분모는 항상 0이 아니다.
    function automatic integer duty_percent(
        input [31:0] high_ticks,
        input [31:0] period_ticks
    );
        begin
            duty_percent = (high_ticks * 100) / period_ticks;
        end
    endfunction

    // (추가) 설정 요청을 매번 중복 작성하지 않고 task 한 곳에 모은다.
    // cfg_apply는 하강 에지에서 한 클록 동안 유지한다.
    task automatic request_pwm(input [31:0] duty_ticks);
        begin
            @(negedge clk);
            cfg_duty  = duty_ticks;
            cfg_apply = 1'b1;
            $display("REQUEST t=%0d ns duty=%0d", $time, duty_ticks);

            @(negedge clk);
            cfg_apply = 1'b0;

            // 먼저 Shadow 저장 완료를 확인한 뒤 적용 완료를 기다린다.
            // pending=0만 즉시 검사하면 이전 상태를 오인할 수 있다.
            wait (pending === 1'b1);
            wait (pending === 1'b0);
            #1;
            $display("APPLIED t=%0d ns duty=%0d percent=%0d",
                $time, active_duty,
                duty_percent(active_duty, active_period));
        end
    endtask

    // (추가) 한 PWM 주기의 8개 하강 에지에서 출력을 샘플링한다.
    // 표본 개수를 표시할 뿐, 아직 기대값과 자동 비교하지 않는다.
    task automatic observe_one_period;
        integer cycle_index;
        integer high_samples;
        begin
            high_samples = 0;

            for (cycle_index = 0; cycle_index < 8;
                 cycle_index = cycle_index + 1) begin
                @(negedge clk);
                if (pwm_out === 1'b1)
                    high_samples = high_samples + 1;

                $display("SAMPLE duty=%0d cycle=%0d pwm=%b",
                    active_duty, cycle_index, pwm_out);
            end

            $display("OBSERVED duty=%0d HIGH=%0d/8",
                active_duty, high_samples);
        end
    endtask

`ifdef VCD
    initial begin
        $dumpfile("ch03_pwm_reusable_stimulus.vcd");
        $dumpvars(0, tb_pwm_reusable_stimulus);
    end
`endif

    // (추가) 시뮬레이션 무한 대기를 방지하기 위한 안전 종료.
    initial begin
        #2000;
        // (변경) 제한 시간 초과를 실행 오류로 전달한다.
        $fatal(1, "TIMEOUT: PWM 설정 완료 신호를 확인하세요.");
    end

    integer duty_step;

    initial begin
        resetn       = 1'b0;
        cfg_apply    = 1'b0;
        cfg_period   = 32'd8;
        cfg_duty     = 32'd0;
        cfg_enable   = 1'b1;
        cfg_polarity = 1'b0;

        $display("=== CH03 REUSABLE STIMULUS START ===");

        // (추가) 리셋을 두 번의 하강 에지 동안 유지한다.
        repeat (2) @(negedge clk);
        resetn = 1'b1;

        // (추가) 0, 2, 4, 6, 8클록의 Duty를 순서대로 시험한다.
        // cfg_period=8이므로 0%, 25%, 50%, 75%, 100%가 된다.
        for (duty_step = 0; duty_step <= 8;
             duty_step = duty_step + 2) begin
            request_pwm(duty_step);
            observe_one_period();
        end

        $display("=== CH03 END: OBSERVATION ONLY ===");
        $finish;
    end
endmodule

코드 풀이

request_pwm(duty_step)는 하강 에지에서 듀티와 요청을 설정하고 다음 하강 에지에서 요청을 내립니다. wait 두 문장이 요청 수락과 적용 완료를 확인합니다. #1은 비차단 대입 갱신 후 안정된 상태를 읽기 위한 TB 관찰 지연입니다.

observe_one_period()는 이후 8개 하강 에지에서 pwm_out을 읽습니다. HIGH인 경우만 high_samples를 증가시킵니다. 관찰값을 기록할 뿐 기대값과 자동 비교하지 않습니다. $fatal(1,...)은 무한 대기를 방지하는 안전 종료이고 정상 동작의 자동 정답 판정은 제4장에서 다룹니다.
