01원본 RTL과 신호 계약

DUT(디유티, 검증 대상 회로)는 여섯 포트를 가진 조합 연결 회로입니다. 바이트 데이터와 유효 신호는 송신 쪽으로, 준비 신호는 수신 쪽으로 전달합니다. 내부 FIFO나 클록·리셋은 없습니다.

reference_rtl/uart_echo_controller.v · Verilog
// (추가) 준비 단계 UART Echo controller: pure combinational stream transfer.
module uart_echo_controller(
    input wire [7:0] rx_data_i,
    input wire rx_valid_i,
    output wire rx_ready_o,
    output wire [7:0] tx_data_o,
    output wire tx_valid_o,
    input wire tx_ready_i
);
    assign rx_ready_o=tx_ready_i;
    assign tx_valid_o=rx_valid_i;
    assign tx_data_o=rx_data_i;
endmodule
입력출력계약
rx_data_i[7:0]tx_data_o[7:0]8비트 그대로
rx_valid_itx_valid_o유효 신호 전달
tx_ready_irx_ready_o준비 신호 역방향 전달

TB의 #1은 조합 출력 관찰용 시뮬레이션 시간입니다. 실제 UART 비트 타이밍이나 회로 지연을 의미하지 않습니다.

02Packed·Unpacked 배열

Packed array(팩트 어레이, 연속 비트 배열)는 여러 바이트를 하나의 벡터로 묶습니다. Unpacked array(언팩트 어레이, 원소 배열)는 바이트를 개별 원소로 관리합니다.

SystemVerilog · 실제 TB에서 발췌
logic [3:0][7:0] packed_bytes;
logic [7:0] unpacked_bytes [0:3];

packed_bytes = {8'h41, 8'h42, 8'h43, 8'h44};
// 인덱스 3 → 0, 2 → 1, 1 → 2, 0 → 3
for (i = 0; i < 4; i = i + 1)
    unpacked_bytes[i] = packed_bytes[3-i];

왼쪽의 41(A)이 packed_bytes[3]에 들어갑니다. 따라서 3-i를 사용해야 A·B·C·D 순서로 복사됩니다. 단순히 packed_bytes[i]를 사용하면 D·C·B·A로 역전됩니다.

03Queue · 기대 데이터의 수락 순서

Queue(큐, 크기를 바꿀 수 있는 순서 자료구조)는 TB에서 비교할 기대 바이트를 저장합니다. push_back()은 뒤에 추가하고 pop_front()는 앞에서 꺼내며, size()는 현재 원소 수를 반환합니다.

SystemVerilog · 큐 선언과 초기화
logic [7:0] expected_q[$];
for (i = 0; i < 4; i = i + 1)
    expected_q.push_back(unpacked_bytes[i]);
관찰 ns입력 사례validready처리남은 큐
1IDLE01유지A B C D
2SEND A11A 제거B C D
3STALL B10유지B C D
4RESUME B11B 제거C D
5SEND C11C 제거D
6SEND D11D 제거비어 있음

여기서 수락은 sample.valid && sample.ready가 참인 입력 사례를 TB가 수락으로 모델링한 것입니다. 출력의 data·valid·ready는 별도로 비교합니다. 실제 클록 에지의 전송 수락이나 모든 Ready/Valid(레디/밸리드, 준비/유효 신호) 프로토콜을 증명하는 검사는 아닙니다.

B에서 ready가 0이면 큐를 유지해야 합니다. 다음 RESUME에서 같은 B를 다시 제시하면 B가 제거됩니다. DUT는 값을 저장하지 않으므로 B를 유지하는 것은 입력을 제어하는 TB의 책임입니다.

04Package · 공통 자료형 분리

Package(패키지, 공통 선언 묶음)에 구조체와 열거형을 정의합니다. import uart_expect_pkg::*;는 이미 컴파일된 패키지의 선언을 참조합니다.

tb/ch06/uart_expect_pkg.sv · SystemVerilog
// 제06장: 기대값의 자료형을 재사용 가능한 패키지에 모은다.
// 이 파일은 검증용이며 합성 대상 DUT에 포함하지 않는다.
package uart_expect_pkg;
    // packed: valid, ready, data를 하나의 10비트 값으로 묶는다.
    typedef struct packed {
        logic       valid;
        logic       ready;
        logic [7:0] data;
    } uart_sample_t;

    // 검증 결과 기록용 2상태 열거형.
    typedef enum bit [1:0] {
        CASE_IDLE  = 2'd0,
        CASE_SEND  = 2'd1,
        CASE_STALL = 2'd2,
        CASE_RESUME = 2'd3
    } case_kind_t;
endpackage
비트 위치필드폭
[9]valid1
[8]ready1
[7:0]data8

제05장과 비교: 같은 이름의 uart_sample_t라도 이 장의 필드 선언 순서는 valid → ready → data로 다릅니다. 따라서 10비트 연결 인자의 순서 역시 달라집니다. 두 실습은 독립 프로젝트입니다. 제05장의 구조체 선언을 복사하여 섞지 않습니다.

case_kind_t는 사례 이름을 나타내는 2비트 열거형이며 DUT의 FSM 상태가 아닙니다. 실제 신호 데이터는 4상태 logic을 유지합니다.

05테스트벤치 전체 코드

패키지의 자료형을 가져오고 원본 RTL의 여섯 포트를 연결합니다. 네 개의 기대값을 저장한 다음 여섯 사례에 대해 신호를 비교하고, 수락으로 모델링한 사례에서만 큐의 첫 원소를 비교합니다.

tb/ch06/tb_uart_arrays_queues.sv · SystemVerilog
`timescale 1ns/1ps
// 제06장: packed/unpacked 배열, queue, package로 UART Echo 기대값을 관리.
// 실제 DUT는 조합 회로이며 UART 직렬 전송기나 FIFO가 아니다.
module tb_uart_arrays_queues;
    import uart_expect_pkg::*;

    logic [7:0] rx_data_i;
    logic       rx_valid_i;
    logic       tx_ready_i;
    wire [7:0]  tx_data_o;
    wire        tx_valid_o;
    wire        rx_ready_o;

    // 실제 원본의 여섯 포트를 정확한 이름으로 연결한다.
    uart_echo_controller dut (
        .rx_data_i(rx_data_i),
        .rx_valid_i(rx_valid_i),
        .rx_ready_o(rx_ready_o),
        .tx_data_o(tx_data_o),
        .tx_valid_o(tx_valid_o),
        .tx_ready_i(tx_ready_i)
    );

    // packed 배열: 4개 바이트를 하나의 32비트 벡터로 저장한다.
    logic [3:0][7:0] packed_bytes;
    // unpacked 배열: 4개의 독립된 8비트 원소를 보관한다.
    logic [7:0] unpacked_bytes [0:3];

    // queue: 기대되는 출력 데이터를 입력 순서대로 보관한다.
    // 원본 DUT 내부에 FIFO가 있다는 뜻이 아니다.
    logic [7:0] expected_q[$];
    uart_sample_t sample;
    case_kind_t kind;
    logic [7:0] expected_byte;
    integer checks = 0;
    integer failures = 0;
    integer i;

    // 이 TB는 입력 사례의 valid/ready가 모두 1이면 수락으로 모델링한다.
    // DUT 자체에는 클록과 실제 수락 에지 또는 저장소가 없다.
    task automatic apply_sample(
        input case_kind_t next_kind,
        input uart_sample_t next_sample
    );
        begin
            kind = next_kind;
            sample = next_sample;

            rx_data_i  = sample.data;
            rx_valid_i = sample.valid;
            tx_ready_i = sample.ready;
            #1; // 조합 전파 관찰용 시간, 실제 DUT 레이턴시 아님.

            checks = checks + 1;
            if ((tx_data_o !== sample.data) ||
                (tx_valid_o !== sample.valid) ||
                (rx_ready_o !== sample.ready)) begin
                failures = failures + 1;
                $error("SIGNAL_MISMATCH kind=%0d data=%h", kind, sample.data);
            end

            if (sample.valid && sample.ready) begin
                if (expected_q.size() == 0) begin
                    failures = failures + 1;
                    $error("QUEUE_UNDERFLOW kind=%0d", kind);
                end else begin
                    expected_byte = expected_q.pop_front();
                    checks = checks + 1;
                    if (tx_data_o !== expected_byte) begin
                        failures = failures + 1;
                        $error("DATA_MISMATCH got=%h expected=%h",
                            tx_data_o, expected_byte);
                    end else begin
                        $display("ACCEPT t=%0d ns data=%h remain=%0d",
                            $time, tx_data_o, expected_q.size());
                    end
                end
            end else begin
                $display("HOLD t=%0d ns kind=%0d valid=%b ready=%b",
                    $time, kind, sample.valid, sample.ready);
            end
        end
    endtask

`ifdef VCD
    // (변경) Icarus 실행에서 VCD 기록을 활성화한다.
    initial begin
        $dumpfile("ch06_uart_arrays_queues.vcd");
        $dumpvars(0, tb_uart_arrays_queues);
    end
`endif

    initial begin
        rx_data_i  = 8'h00;
        rx_valid_i = 1'b0;
        tx_ready_i = 1'b0;
        packed_bytes = {8'h41, 8'h42, 8'h43, 8'h44};

        // packed 인덱스 3은 최상위 바이트(41), 인덱스 0은 44.
        for (i = 0; i < 4; i = i + 1)
            unpacked_bytes[i] = packed_bytes[3-i];

        // 아직 전송 전이므로 예상값 네 개를 큐에 먼저 쌓는다.
        for (i = 0; i < 4; i = i + 1)
            expected_q.push_back(unpacked_bytes[i]);

        $display("=== CH06 ARRAYS QUEUES PACKAGES START ===");
        $display("ARRAY packed=%h first=%h last=%h",
            packed_bytes, unpacked_bytes[0], unpacked_bytes[3]);
        $display("QUEUE size=%0d", expected_q.size());

        // (변경) 구조체 필드 순서 valid[9], ready[8], data[7:0]의 비트 연결.
        // 유효하지 않은 데이터: queue에서 꺼내지 않는다.
        apply_sample(CASE_IDLE, {1'b0, 1'b1, 8'h00});

        // A는 수락, B는 ready=0인 동안 수락하지 않는다.
        apply_sample(CASE_SEND, {1'b1, 1'b1, 8'h41});
        apply_sample(CASE_STALL, {1'b1, 1'b0, 8'h42});
        apply_sample(CASE_RESUME, {1'b1, 1'b1, 8'h42});

        // C, D를 이어서 전송하고 큐를 비운다.
        apply_sample(CASE_SEND, {1'b1, 1'b1, 8'h43});
        apply_sample(CASE_SEND, {1'b1, 1'b1, 8'h44});

        checks = checks + 1;
        if (expected_q.size() != 0) begin
            failures = failures + 1;
            $error("QUEUE_NOT_EMPTY remain=%0d", expected_q.size());
        end

        // (추가) 큐가 비어 있어도 IDLE·STALL 검사가 누락될 수 있다.
        if (checks != 11)
            $fatal(1, "FAIL COUNT checks=%0d expected=11", checks);
        if (failures == 0) begin
            $display("PASS checks=%0d failures=0 queue=0", checks);
            $finish;
        end else begin
            $fatal(1, "FAIL checks=%0d failures=%0d", checks, failures);
        end
    end

    // wait 없이 종료되도록 전체 시간 상한을 별도로 설정한다.
    initial begin
        #100;
        $fatal(1, "TIMEOUT: testbench did not finish");
    end
endmodule

07오류 분석과 검증 범위

큐가 비어 있더라도 IDLE 또는 STALL 검사가 생략되면 최종 검사 횟수가 달라집니다. checks가 11인지 별도 확인합니다.

증상확인 사항
패키지 또는 타입 오류컴파일 순서 및 import, 설치 버전
큐 문법 오류시뮬레이터의 queue·packed 배열 지원 확인
SIGNAL_MISMATCH원본 3개 연속 대입과 구조체 필드 위치
DATA_MISMATCH기대 큐의 A·B·C·D 순서 및 실제 출력
QUEUE_UNDERFLOW기대값보다 수락으로 처리한 사례가 많음
QUEUE_NOT_EMPTY남은 기대값이 있음
TIMEOUTTB 종료 경로 확인

반례: 배열 선택을 packed_bytes[i]로 바꾸면 첫 기대값 D와 실제 A가 불일치합니다. B의 대기 중에도 큐를 꺼내도록 변경하면 이후 비교 순서가 어긋납니다. 반면 모든 출력 신호가 맞더라도 입력 사례 사이의 실제 전송 유지 규칙까지 검증한 것은 아닙니다.

다음 제07장은 interface(인터페이스, 신호 묶음), modport(모드포트, 방향 지정), clocking block(클로킹 블록, 구동·관찰 시점 지정)으로 검증 연결을 분리합니다.
