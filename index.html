6부 · 24장단계별 검증기존 RTL 재사용

00교육과정 개요

6부 24장의 독립 검증 과정입니다. 원본 회로의 이해에서 실무 자동 검증까지 단계적으로 확장합니다.

학습 흐름은 문법 이해 → 파형 관찰 → 자동 정답 판정 → 속성·커버리지 → UVM 재사용 → 회귀·보고입니다. 실제 검증에서는 기존 Basys3/SoC RTL을 DUT(검증 대상 회로)로만 참조합니다.

07실습·검증 원칙

① 실제 포트·타이밍 계약 확인 ② 원본 RTL 보존 ③ 테스트코드와 기대 결과 분리 ④ PASS·FAIL·NOT_RUN 구분 ⑤ 시뮬레이터·시드·원본 SHA 기록을 기본으로 합니다.

공통 검증 단계확인할 산출물
원본 RTL → 포트·시간 계약모듈·신호·폭·리셋·타이밍
검증 구조 → 시나리오자극·관찰·독립 기대값·정상/경계/오류 조건
TB → 실행 → 판정전체 소스·명령·로그·PASS/FAIL/NOT_RUN

각 장에서 사용하는 예시는 코드 전체를 제시하고 코드 → 예상 출력 → 구문별 해석 → 검증 순으로 설명합니다. 미발행 장은 링크를 제공하지 않아 깨진 탐색을 방지합니다.
