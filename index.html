SYSTEMVERILOG · UVM VERIFICATION

RTL 검증 독립 학습안내서

기초 Testbench에서 UVM, 자동 회귀 검증까지. 이미 구현한 RTL을 다시 만들지 않고 실제 검증 대상으로 활용합니다.

6부 · 24장각 장 2시간 · 1시간씩 분리기존 RTL 재사용

00교육과정 개요

6부 24장 · 총 48시간의 독립 검증 과정입니다. 제1장부터 단계적으로 발행하며, 1장당 1교시(60분)와 2교시(60분)를 구분합니다.

학습 흐름은 문법 이해 → 파형 관찰 → 자동 정답 판정 → 속성·커버리지 → UVM 재사용 → 회귀·보고입니다. 실제 검증에서는 기존 Basys3/SoC RTL을 DUT(검증 대상 회로)로만 참조합니다.
