제15장 · AXI4-Lite 레지스터 검증

독립 AW/W 거래부터 WSTRB, 응답 유지, 리셋까지 실제 RTL로 확인합니다.

PART 04 · CHAPTER 151교시 60분 + 2교시 60분원본 RTL 변경 없음

00개요 · 레지스터 검증을 버스 거래로 확장

제15장은 AXI4-Lite(에이엑스아이 포 라이트, 경량 메모리 매핑 버스)의 다섯 채널을 실제 기존 RTL에 연결해 검증합니다. AW(쓰기 주소), W(쓰기 데이터), B(쓰기 응답), AR(읽기 주소), R(읽기 데이터)은 서로 독립적으로 준비·수락됩니다. 단순히 값을 썼는지 확인하는 수준을 넘어, 주소와 데이터의 도착 순서가 바뀌어도 같은 결과가 나오는지 확인합니다.

1교시 · 60분0~20분 5채널 구조 / 20~40분 실제 레지스터 맵 / 40~60분 handshake·WSTRB
2교시 · 60분60~90분 전체 TB / 90~105분 실행·예상 결과 / 105~120분 실패 분석

011교시 ① · 다섯 채널의 시간 계약 (0~20분)

주소 채널 s_axi_awvalid와 데이터 채널 s_axi_wvalid는 같은 클록에 도착할 필요가 없습니다. 원본 axi4lite_slave_adapter는 aw_stored와 w_stored에 각각 저장합니다. 두 저장 플래그가 모두 1이고 이전 쓰기 응답이 없다면 write_commit이 1이 됩니다. 이때 wr_en이 레지스터 뱅크에 전달됩니다.

응답 s_axi_bvalid는 s_axi_bready가 0인 동안 유지됩니다. 읽기 주소가 수락되면 s_axi_rdata가 레지스터 값을 캡처하고 s_axi_rvalid가 1이 됩니다. 이 역시 s_axi_rready가 0이면 값과 valid를 유지합니다.

021교시 ② · 원본 레지스터 맵과 WSTRB (20~40분)

Offset원본 레지스터특징
0x00REG_CONTROLenable_o[0], mode_o[2:1] · 바이트 0 쓰기
0x04REG_STATUSbusy_i, done_i, error_i 읽기
0x08REG_COMMANDstart_pulse_o, clear_pulse_o · 1클록 펄스
0x0CREG_IRQ_STATUSW1C(1 쓰면 해제) 상태
0x10REG_DATA_IN32비트 데이터, WSTRB 바이트 단위
0x14REG_DATA_OUT하드웨어 입력 값 읽기
0x18REG_VERSION0x00010000
0x1CREG_ID0x524D4150

WSTRB[3:0](라이트 스트로브, 쓰기 바이트 활성 신호)는 각 바이트의 갱신 여부를 결정합니다. 먼저 0x11223344를 전체 쓰고, 0xAABBCCDD를 4'b0101로 쓰면 바이트 0과 2만 교체되어 결과는 0x11BB33DD입니다. 이 결과는 단순한 비트마스크 계산이 아니라 원본 custom_register_bank의 wr_strb 분기와 일치합니다.

031교시 ③ · B/R 응답 지연과 자동 판정 (40~60분)

AW만 수락된 시점에는 wr_en=0이고 B 응답도 생성되지 않아야 합니다. W만 먼저 수락된 경우도 동일합니다. 반면 두 채널이 모두 수락된 뒤에는 쓰기가 한 번만 반영되어야 합니다. s_axi_bready=0으로 3클록을 기다려도 s_axi_bvalid=1을 유지하는지 확인합니다.

읽기에서도 s_axi_rready=0으로 3클록 대기하는 동안 s_axi_rdata가 유지되어야 합니다. 예상값과 비교할 때 !==를 사용해 X/Z(미정·고임피던스) 값까지 실패로 판정합니다.

042교시 ① · 테스트벤치 전체 코드 (60~90분)

원본 두 모듈의 포트를 그대로 인스턴스화합니다. send_aw, send_w, finish_b, read_expect를 독립된 task(태스크, 반복 가능한 검증 절차)로 작성하여 전송 순서와 검증 책임을 구분합니다.

tb/ch15/tb_axi4lite_registers.sv · SystemVerilog · 전체 코드
`timescale 1ns/1ps
// 제15장: 기존 AXI4-Lite 어댑터 + 레지스터 뱅크를 읽기 전용 DUT로 검증.
// AW/W 독립 수락, B/R 대기 유지, WSTRB 부분 쓰기, Reset을 자동 판정한다.
module tb_axi4lite_registers;
    reg clk=0, resetn=0;
    always #5 clk=~clk;
    reg [31:0] awaddr=0, wdata=0, araddr=0;
    reg [3:0] wstrb=0;
    reg awvalid=0, wvalid=0, bready=0, arvalid=0, rready=0;
    wire awready,wready,bvalid,arready,rvalid;
    wire [1:0] bresp,rresp;
    wire [31:0] rdata;
    wire wr_en;
    wire [7:0] wr_offset,rd_offset;
    wire [31:0] wr_data,rd_data;
    wire [3:0] wr_strb;
    wire enable_o,start_pulse_o,clear_pulse_o;
    wire [1:0] mode_o,irq_status_o;
    wire [31:0] data_in_o;
    integer checks=0, commits=0;
    reg [31:0] captured;

    axi4lite_slave_adapter dut (
        .s_axi_aclk(clk), .s_axi_aresetn(resetn),
        .s_axi_awaddr(awaddr), .s_axi_awprot(3'b0),
        .s_axi_awvalid(awvalid), .s_axi_awready(awready),
        .s_axi_wdata(wdata), .s_axi_wstrb(wstrb),
        .s_axi_wvalid(wvalid), .s_axi_wready(wready),
        .s_axi_bresp(bresp), .s_axi_bvalid(bvalid), .s_axi_bready(bready),
        .s_axi_araddr(araddr), .s_axi_arprot(3'b0),
        .s_axi_arvalid(arvalid), .s_axi_arready(arready),
        .s_axi_rdata(rdata), .s_axi_rresp(rresp),
        .s_axi_rvalid(rvalid), .s_axi_rready(rready),
        .wr_en(wr_en), .wr_offset(wr_offset), .wr_data(wr_data),
        .wr_strb(wr_strb), .rd_offset(rd_offset), .rd_data(rd_data)
    );
    custom_register_bank bank (
        .clk(clk), .resetn(resetn), .wr_en(wr_en),
        .wr_offset(wr_offset), .wr_data(wr_data), .wr_strb(wr_strb),
        .rd_offset(rd_offset), .rd_data(rd_data),
        .busy_i(1'b0), .done_i(1'b0), .error_i(1'b0),
        .irq_done_event_i(1'b0), .irq_error_event_i(1'b0),
        .data_out_i(32'h12345678), .enable_o(enable_o),
        .mode_o(mode_o), .start_pulse_o(start_pulse_o),
        .clear_pulse_o(clear_pulse_o), .data_in_o(data_in_o),
        .irq_status_o(irq_status_o)
    );
    // 두 채널을 모두 수락한 다음에만 wr_en이 1회 발생해야 한다.
    always @(posedge clk) if(resetn && wr_en) commits=commits+1;

    task automatic send_aw(input [31:0] address);
        integer guard;
        begin
            @(negedge clk);
            awaddr=address; awvalid=1;
            guard=0;
            while(awready !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if(guard>100) $fatal(1,"FAIL AW_TIMEOUT");
            end
            @(posedge clk);
            @(negedge clk);
            awvalid=0;
        end
    endtask

    task automatic send_w(input [31:0] data,input [3:0] strobe);
        integer guard;
        begin
            @(negedge clk);
            wdata=data; wstrb=strobe; wvalid=1;
            guard=0;
            while(wready !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if(guard>100) $fatal(1,"FAIL W_TIMEOUT");
            end
            @(posedge clk);
            @(negedge clk);
            wvalid=0;
        end
    endtask

    task automatic finish_b;
        integer guard;
        begin
            guard=0;
            while(bvalid !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if(guard>100) $fatal(1,"FAIL B_TIMEOUT");
            end
            if(bresp !== 2'b00) $fatal(1,"FAIL BRESP");
            // 응답을 받지 않는 동안 BVALID는 내려가면 안 된다.
            repeat(3) begin
                @(negedge clk);
                if(bvalid !== 1'b1 || awready !== 1'b0 ||
                   wready !== 1'b0) $fatal(1,"FAIL B_HOLD");
            end
            bready=1;
            @(posedge clk);
            @(negedge clk);
            bready=0;
            if(bvalid !== 1'b0) $fatal(1,"FAIL B_CLEAR");
            checks=checks+1;
        end
    endtask

    task automatic read_expect(input [31:0] address,input [31:0] expected);
        integer guard;
        begin
            @(negedge clk);
            araddr=address; arvalid=1;
            guard=0;
            while(arready !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if(guard>100) $fatal(1,"FAIL AR_TIMEOUT");
            end
            @(posedge clk);
            @(negedge clk);
            arvalid=0;
            if(rvalid !== 1'b1 || rresp !== 2'b00 || rdata !== expected)
                $fatal(1,"FAIL READ addr=%h got=%h exp=%h",address,rdata,expected);
            captured=rdata;
            repeat(3) begin
                @(negedge clk);
                if(rvalid !== 1'b1 || arready !== 1'b0 ||
                   rdata !== captured) $fatal(1,"FAIL R_HOLD");
            end
            rready=1;
            @(posedge clk);
            @(negedge clk);
            rready=0;
            if(rvalid !== 1'b0) $fatal(1,"FAIL R_CLEAR");
            checks=checks+1;
        end
    endtask

    initial begin
        #20000;
        $fatal(1,"FAIL GLOBAL_TIMEOUT");
    end

    initial begin
        $dumpfile("ch15_axi4lite.vcd");
        $dumpvars(0,tb_axi4lite_registers);
        repeat(4) @(negedge clk);
        if(awready !== 1'b0 || wready !== 1'b0 ||
           arready !== 1'b0) $fatal(1,"FAIL RESET_READY");
        resetn=1;
        @(negedge clk);

        // T1: AW를 먼저 보내고 W가 오기 전에는 commit하지 않는다.
        send_aw(32'h10);
        repeat(3) @(negedge clk);
        if(commits!=0 || bvalid !== 1'b0) $fatal(1,"FAIL AW_ONLY");
        send_w(32'h11223344,4'b1111);
        finish_b();
        read_expect(32'h10,32'h11223344);
        $display("T1_AW_BEFORE_W_PASS");

        // T2: W를 먼저 보내도 독립 버퍼에 보관된다.
        send_w(32'hAABBCCDD,4'b0101);
        repeat(3) @(negedge clk);
        if(commits!=1 || bvalid !== 1'b0) $fatal(1,"FAIL W_ONLY");
        send_aw(32'h10);
        finish_b();
        read_expect(32'h10,32'h11BB33DD);
        $display("T2_W_BEFORE_AW_WSTRB_PASS");

        // T3: CONTROL, VERSION, ID 및 읽기 응답 유지.
        send_aw(32'h00);
        send_w(32'h00000005,4'b0001);
        finish_b();
        read_expect(32'h00,32'h00000005);
        read_expect(32'h18,32'h00010000);
        read_expect(32'h1C,32'h524D4150);
        if(enable_o !== 1'b1 || mode_o !== 2'b10)
            $fatal(1,"FAIL CONTROL_OUTPUT");
        $display("T3_CONTROL_RO_PASS");

        // T4: 리셋 후 CONTROL/DATA_IN 초기화, 채널 준비 복구.
        @(negedge clk);
        resetn=0;
        repeat(3) @(negedge clk);
        if(bvalid !== 1'b0 || rvalid !== 1'b0 ||
           enable_o !== 1'b0 || data_in_o !== 32'b0)
            $fatal(1,"FAIL RESET_CLEAR");
        resetn=1;
        @(negedge clk);
        read_expect(32'h10,32'h00000000);
        read_expect(32'h00,32'h00000000);
        if(commits!=3 || checks!=10)
            $fatal(1,"FAIL COUNTS commits=%0d checks=%0d",commits,checks);
        $display("T4_RESET_PASS");
        $display("PASS CH15 commits=%0d checks=%0d",commits,checks);
        $finish;
    end
endmodule

코드 풀이 — 중요한 네 지점

send_aw()와 send_w()는 각각 자신의 ready를 기다린 후 상승 에지에서 한 번 수락합니다. commits는 wr_en 펄스를 관찰하여 중복 쓰기를 검사합니다. finish_b()는 B 응답을 일부러 받지 않고 유지 여부를 확인합니다. read_expect()는 R 채널의 응답값·응답 코드·유지 조건을 함께 검사합니다.

052교시 ② · 실행 명령과 예상 출력 (90~105분)

Ubuntu에서 저장소 루트로 이동한 뒤 bash scripts/run_ch15.sh를 실행합니다. Bash(배시, 명령 실행 셸) 스크립트는 Icarus Verilog(아이베릴로그, Verilog 시뮬레이터)로 두 원본 RTL과 TB를 컴파일하고, vvp(브이브이피, 시뮬레이션 실행기)로 결과를 기록합니다. 원본 파일을 변경하지 않으며 로그·VCD는 .build/ch15/에 생성됩니다.

scripts/run_ch15.sh · Bash · 전체 코드
#!/usr/bin/env bash
# 사용: bash scripts/run_ch15.sh
# 원본 RTL은 읽기 전용; 시뮬레이션 산출물은 .build/ch15에만 생성한다.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
RTL="${RTL_DIR:-$ROOT/reference_rtl}"
for f in axi4lite_slave_adapter.v custom_register_bank.v; do
  if [[ ! -f "$RTL/$f" ]]; then
    echo "NOT_RUN: missing $RTL/$f" >&2
    exit 2
  fi
done
if ! command -v iverilog >/dev/null 2>&1 || ! command -v vvp >/dev/null 2>&1; then
  echo "NOT_RUN: Icarus Verilog not installed" >&2
  exit 2
fi
mkdir -p "$ROOT/.build/ch15"
cd "$ROOT/.build/ch15"
iverilog -g2012 -s tb_axi4lite_registers -o sim \
  "$RTL/axi4lite_slave_adapter.v" "$RTL/custom_register_bank.v" \
  "$ROOT/tb/ch15/tb_axi4lite_registers.sv"
vvp sim | tee simulation.log
grep -q '^PASS CH15 commits=3 checks=10$' simulation.log

예상 출력 — 실제 실행 로그 아님

예상 출력 · text · 전체 코드
T1_AW_BEFORE_W_PASS\nT2_W_BEFORE_AW_WSTRB_PASS\nT3_CONTROL_RO_PASS\nT4_RESET_PASS\nPASS CH15 commits=3 checks=10\n

예상 출력은 코드의 목표 판정 문자열입니다. 실제 시뮬레이션 결과와 구분해야 하며, 컴파일·실행이 확인되지 않은 상태는 NOT_RUN으로 기록합니다.

062교시 ③ · 실패 분석 및 검증 기록 (105~120분)

실패 증상원인 확인
AW_ONLY에서 commit 발생aw_stored와 w_stored 조건, W 채널 잔류 여부
B_HOLD 실패s_axi_bready가 0인 동안 s_axi_bvalid 유지 여부
READ 불일치rd_offset의 하위 8비트, AR 수락 시 rd_data 캡처
WSTRB 실패wr_strb[0]·wr_strb[2]만 활성화되었는지 확인
Reset 실패s_axi_aresetn과 resetn 동시 적용 확인

원본은 AWPROT/ARPROT를 기능적으로 사용하지 않고, AXI 응답은 정상 OKAY를 반환합니다. 이 장의 정상 시험은 미매핑 주소의 오류 응답이나 전체 AXI 규격 준수를 보증하지 않습니다. RTL_SIM: NOT_RUN · BROWSER_VISUAL: NOT_RUN.
