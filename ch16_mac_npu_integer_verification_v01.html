제16장 · MAC·NPU 정수 연산 검증

INT8 부호·누산·파이프라인 지연을 기존 RTL과 독립 모델로 검증합니다.

PART 04 · CHAPTER 161교시 60분 + 2교시 60분원본 RTL 변경 없음

00개요 · INT8 MAC을 검증하는 이유

MAC(맥, 곱셈·누산)은 NPU(엔피유, 신경망 연산 장치)의 기본 계산입니다. 두 입력을 곱한 뒤 이전 누산값에 더합니다. 부호가 있는 정수에서는 곱셈 폭, 부호 확장, 누산 폭, 결과 지연을 각각 검증해야 합니다.

이 장은 기존 mac_core와 mac_pipeline_core를 그대로 재사용합니다. NPU 전체 모델을 새로 만드는 대신, 가장 작은 계산 블록의 정답을 확정하는 실습입니다.

1교시 60분0~20분 INT8 수치 / 20~40분 실제 RTL 포트 / 40~60분 파이프라인 타이밍
2교시 60분60~90분 전체 TB / 90~105분 Python 독립 모델·실행 / 105~120분 검증·장애 분석

011교시 ① · INT8 부호와 곱셈 폭 (0~20분)

INT8(8비트 부호 있는 정수)의 범위는 -128~127입니다. 두 8비트 값을 곱하면 결과를 온전히 담는 데 16비트가 필요합니다. 예를 들어 -128 × -128은 16384이며 -128 × 127은 -16256입니다. 두 값 모두 16비트 signed(부호 있는 정수)로 표현할 수 있습니다.

이번 TB는 DATA_WIDTH=8, ACC_WIDTH=16을 사용합니다. 누산 결과가 범위를 넘으면 원본 RTL과 동일하게 상위 비트를 버리고 16비트 2의 보수로 순환합니다. 이것은 포화 연산이 아닙니다.

021교시 ② · 실제 포트와 우선순위 (20~40분)

포트의미
clk, resetn상승 에지 동기식 리셋, active-low
clear_i누산 초기화, valid 입력보다 우선
valid_i, a_i, b_i유효한 signed 곱셈 입력
acc_o, valid_o누산 결과와 결과 유효 신호

원본 두 모듈 모두 !resetn → clear_i → valid_i 우선순위를 갖습니다. clear_i=1인 에지에 들어온 곱은 버려집니다. valid_i=0이면 누산값을 유지합니다. 원본 기본 파라미터는 16/40비트지만 TB 인스턴스에서 8/16비트로 지정합니다.

031교시 ③ · 파이프라인 지연 (40~60분)

mac_core는 입력이 유효한 상승 에지에서 곱을 즉시 누산 레지스터에 반영합니다. mac_pipeline_core는 먼저 product_q와 product_valid_q에 곱을 저장하고, 다음 상승 에지에 그 곱을 누산합니다. 따라서 같은 입력이라도 acc_o와 valid_o의 비교 시점은 한 클록 다릅니다.

파이프라인은 클록 속도를 높이기 위한 구조이지 수치 결과를 바꾸는 구조가 아닙니다. clear_i와 resetn이 활성화되면 아직 누산되지 않은 product_q의 유효 상태도 폐기됩니다.

042교시 ① · 전체 SystemVerilog TB (60~90분)

두 DUT에 같은 입력을 연결하고, 테스트벤치 안에서 서로 다른 시간 모델을 유지합니다. 모델은 DUT 내부 레지스터를 읽지 않습니다. posedge clk 뒤 #1에서 NBA(논블로킹 대입 갱신)가 끝난 결과를 비교합니다.

tb/ch16/tb_mac_integer.sv · SystemVerilog · 전체 코드 · 실행 미검증
`timescale 1ns/1ps
// 제16장: 원본 MAC 및 파이프라인 MAC의 INT8 signed 누산 검증.
// RTL 수정 없이 동일 입력을 두 DUT에 주고 서로 다른 출력 지연을 검사한다.
module tb_mac_integer;
    reg clk = 0;
    reg resetn = 0, clear_i = 0, valid_i = 0;
    reg signed [7:0] a_i = 0, b_i = 0;
    wire signed [15:0] acc_basic, acc_pipe;
    wire valid_basic, valid_pipe;
    reg signed [15:0] model_basic = 0, model_pipe = 0;
    reg signed [15:0] pending_product = 0;
    reg pending_valid = 0;
    reg expected_basic_valid = 0, expected_pipe_valid = 0;
    integer cycles = 0, valid_count = 0, pipe_count = 0;
    integer i;
    reg signed [15:0] product;
    reg signed [7:0] va, vb;

    always #5 clk = ~clk;

    mac_core #(.DATA_WIDTH(8), .ACC_WIDTH(16)) basic (
        .clk(clk), .resetn(resetn), .clear_i(clear_i),
        .valid_i(valid_i), .a_i(a_i), .b_i(b_i),
        .acc_o(acc_basic), .valid_o(valid_basic)
    );
    mac_pipeline_core #(.DATA_WIDTH(8), .ACC_WIDTH(16)) piped (
        .clk(clk), .resetn(resetn), .clear_i(clear_i),
        .valid_i(valid_i), .a_i(a_i), .b_i(b_i),
        .acc_o(acc_pipe), .valid_o(valid_pipe)
    );

    // 기대 모델은 DUT의 내부 신호를 참조하지 않는다.
    // 16비트 누산에서 오버플로는 하위 16비트만 남긴다.
    always @(posedge clk) begin
        if (!resetn || clear_i) begin
            model_basic = 0;
            model_pipe = 0;
            pending_product = 0;
            pending_valid = 0;
            expected_basic_valid = 0;
            expected_pipe_valid = 0;
        end else begin
            expected_pipe_valid = pending_valid;
            if (pending_valid)
                model_pipe = model_pipe + pending_product;
            expected_basic_valid = valid_i;
            if (valid_i) begin
                product = $signed(a_i) * $signed(b_i);
                model_basic = model_basic + product;
                pending_product = product;
            end
            pending_valid = valid_i;
        end
        // 비차단 대입이 완료된 뒤 두 결과를 비교한다.
        #1;
        cycles = cycles + 1;
        if (acc_basic !== model_basic ||
            valid_basic !== expected_basic_valid)
            $fatal(1, "FAIL BASIC cycle=%0d got=%0d/%b expected=%0d/%b",
                   cycles, acc_basic, valid_basic,
                   model_basic, expected_basic_valid);
        if (acc_pipe !== model_pipe ||
            valid_pipe !== expected_pipe_valid)
            $fatal(1, "FAIL PIPE cycle=%0d got=%0d/%b expected=%0d/%b",
                   cycles, acc_pipe, valid_pipe,
                   model_pipe, expected_pipe_valid);
        if (expected_basic_valid) valid_count = valid_count + 1;
        if (expected_pipe_valid) pipe_count = pipe_count + 1;
    end

    // 모든 입력은 하강 에지에서 변경해 상승 에지 경합을 방지한다.
    task automatic apply(
        input bit rst, input bit clr, input bit v,
        input signed [7:0] aa, input signed [7:0] bb
    );
        begin
            @(negedge clk);
            resetn = rst;
            clear_i = clr;
            valid_i = v;
            a_i = aa;
            b_i = bb;
        end
    endtask

    initial begin
        #100000;
        $fatal(1, "FAIL GLOBAL_TIMEOUT");
    end

    initial begin
        $dumpfile("ch16_mac_integer.vcd");
        $dumpvars(0, tb_mac_integer);
        // 최초 2클록 동안 동기 리셋 유지.
        repeat(2) @(negedge clk);
        apply(1, 0, 1, 127, 127);    // 양수 최댓값 곱
        apply(1, 0, 1, -128, 127);   // 음수 최솟값 곱
        apply(1, 0, 1, -128, -128);  // 양수 16384
        apply(1, 0, 0, 8, 9);        // 버블: 누산 유지
        apply(1, 0, 1, 127, 127);    // 누산 오버플로 검증
        apply(1, 1, 1, 100, 100);   // clear 우선: 입력 폐기
        apply(1, 0, 1, -3, 7);      // clear 후 새 누산
        apply(1, 0, 1, 5, -6);
        apply(1, 0, 0, 0, 0);        // 파이프라인 마지막 곱 배출
        apply(0, 0, 1, 2, 3);        // reset 우선
        apply(1, 0, 1, -128, 127);
        apply(1, 0, 0, 0, 0);
        apply(1, 0, 0, 0, 0);
        @(negedge clk);
        if (valid_count < 6 || pipe_count < 5)
            $fatal(1, "FAIL COVERAGE basic=%0d pipe=%0d",
                   valid_count, pipe_count);
        $display("PASS CH16 cycles=%0d basic_valid=%0d pipe_valid=%0d",
                 cycles, valid_count, pipe_count);
        $finish;
    end
endmodule

코드 풀이 — 핵심 구문

product = $signed(a_i) * $signed(b_i)는 부호 있는 곱을 계산합니다. model_basic은 현재 유효 입력을 즉시 더하고, model_pipe는 이전 에지의 pending_product만 더합니다. !==는 X/Z 상태도 오류로 판정합니다. apply()는 하강 에지에 입력을 바꾸므로 DUT 샘플링과 경합하지 않습니다.

052교시 ② · Python 모델과 실행 (90~105분)

Python(파이썬, 범용 프로그래밍 언어)에서는 임의 정밀도 정수를 사용하므로 하위 16비트를 잘라 2의 보수로 되돌려야 RTL과 같은 결과가 됩니다. 아래는 수치 독립 확인용 모델이며 파이프라인 시간 검증은 TB가 담당합니다.

scripts/ch16_reference.py · Python · 전체 코드 · 실행 미검증
#!/usr/bin/env python3
# 제16장: 8비트 부호 있는 곱과 16비트 누산의 독립 정수 모델.
def signed16(value):
    value &= 0xffff
    return value - 65536 if value & 0x8000 else value

vectors = [(127, 127), (-128, 127), (-128, -128), (127, 127)]
acc = 0
for a, b in vectors:
    acc = signed16(acc + a * b)
    print(f"a={a:4d} b={b:4d} product={a*b:7d} acc={acc:7d}")

a= 127 b= 127 product=  16129 acc=  16129\na=-128 b= 127 product= -16256 acc=   -127\na=-128 b=-128 product=  16384 acc=  16257\na= 127 b= 127 product=  16129 acc=  32386\n

Ubuntu에서 python3 scripts/ch16_reference.py로 수치 모델을 실행하고, bash scripts/run_ch16.sh로 Icarus Verilog(아이카루스 베릴로그, RTL 시뮬레이터)를 컴파일·실행합니다. 실행 스크립트는 원본 RTL과 TB를 읽기 전용으로 참조하며 결과를 .build/ch16/에 저장합니다.

scripts/run_ch16.sh · Bash · 전체 코드 · 실행 미검증
#!/usr/bin/env bash
# 제16장: 원본 RTL 사본 두 개를 변경하지 않고 컴파일한다.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
RTL="${RTL_DIR:-$ROOT/reference_rtl}"
if ! command -v iverilog >/dev/null 2>&1 || ! command -v vvp >/dev/null 2>&1; then
  echo "NOT_RUN: iverilog/vvp 설치 필요" >&2
  exit 2
fi
for f in mac_core.v mac_pipeline_core.v; do
  if [[ ! -f "$RTL/$f" ]]; then
    echo "NOT_RUN: $RTL/$f 없음" >&2
    exit 2
  fi
done
mkdir -p "$ROOT/.build/ch16"
cd "$ROOT/.build/ch16"
iverilog -g2012 -s tb_mac_integer -o sim \
  "$RTL/mac_core.v" "$RTL/mac_pipeline_core.v" \
  "$ROOT/tb/ch16/tb_mac_integer.sv"
vvp sim | tee simulation.log
grep -q '^PASS CH16 ' simulation.log
