00개요 · 버스 거래와 레지스터 검증

제14장의 UART는 바이트 스트림을 전달했습니다. 이번 장에서는 AXI4-Lite(에이엑스아이 포 라이트, 경량 메모리 매핑 버스)를 통해 주소와 데이터를 전달하고 레지스터 값을 읽습니다. 독립된 다섯 채널의 수락, 응답 유지, 바이트 쓰기, 리셋을 검증합니다.

설계 개념 연계: 제2부 사용자 AXI IP와 주변장치(amd_soc_p2) 04.2장 03~04절 AXI 핸드셰이크·WSTRB, 10.3장 사양서 2~3절 공통 버스·레지스터 계약, 03.2장 IRQ 관련 설계. 해당 PWM 및 버튼 IP의 RTL과 이 장의 범용 어댑터·레지스터 뱅크는 동일 파일로 확인되지 않았습니다. 이 장은 기존 검증용 스냅샷 두 파일의 독립 실습이며 개념만 연계합니다.

01원본 RTL 전체 · 어댑터와 레지스터 뱅크

reference_rtl/axi4lite_slave_adapter.v · Verilog
module axi4lite_slave_adapter #(
    parameter integer C_S_AXI_ADDR_WIDTH = 32
)(
    input  wire                          s_axi_aclk,
    input  wire                          s_axi_aresetn,

    // AXI4-Lite Write Address Channel
    input  wire [C_S_AXI_ADDR_WIDTH-1:0] s_axi_awaddr,
    input  wire [2:0]                    s_axi_awprot,
    input  wire                          s_axi_awvalid,
    output wire                          s_axi_awready,

    // AXI4-Lite Write Data Channel
    input  wire [31:0]                   s_axi_wdata,
    input  wire [3:0]                    s_axi_wstrb,
    input  wire                          s_axi_wvalid,
    output wire                          s_axi_wready,

    // AXI4-Lite Write Response Channel
    output reg  [1:0]                    s_axi_bresp,
    output reg                           s_axi_bvalid,
    input  wire                          s_axi_bready,

    // AXI4-Lite Read Address Channel
    input  wire [C_S_AXI_ADDR_WIDTH-1:0] s_axi_araddr,
    input  wire [2:0]                    s_axi_arprot,
    input  wire                          s_axi_arvalid,
    output wire                          s_axi_arready,

    // AXI4-Lite Read Data Channel
    output reg  [31:0]                   s_axi_rdata,
    output reg  [1:0]                    s_axi_rresp,
    output reg                           s_axi_rvalid,
    input  wire                          s_axi_rready,

    // Bus-independent register access interface
    output wire                          wr_en,
    output wire [7:0]                    wr_offset,
    output wire [31:0]                   wr_data,
    output wire [3:0]                    wr_strb,

    output wire [7:0]                    rd_offset,
    input  wire [31:0]                   rd_data
);

// AXI response code used by this basic slave.
localparam [1:0] AXI_RESP_OKAY = 2'b00;

// Write Address and Write Data are independent AXI channels.
// Each channel is buffered separately until both are available.
reg                          aw_stored;
reg [C_S_AXI_ADDR_WIDTH-1:0] awaddr_stored;
reg                          w_stored;
reg [31:0]                   wdata_stored;
reg [3:0]                    wstrb_stored;

wire write_commit;

// Single-outstanding-write policy:
// Do not accept a new write while a response is pending.
assign s_axi_awready =
    s_axi_aresetn && !aw_stored && !s_axi_bvalid;

assign s_axi_wready =
    s_axi_aresetn && !w_stored && !s_axi_bvalid;

// Register-bank write occurs only after BOTH address and data
// channels have completed their independent handshakes.
assign write_commit =
    aw_stored && w_stored && !s_axi_bvalid;

assign wr_en     = write_commit;
assign wr_offset = awaddr_stored[7:0];
assign wr_data   = wdata_stored;
assign wr_strb   = wstrb_stored;

// Read side accepts one address only when no previous R response
// is waiting for the master.
assign s_axi_arready =
    s_axi_aresetn && !s_axi_rvalid;

// custom_register_bank read path is combinational.
// The address presented during AR handshake selects rd_data.
assign rd_offset = s_axi_araddr[7:0];

// AWPROT / ARPROT are not used by this educational register slave.
wire unused_prot;
assign unused_prot = ^{s_axi_awprot, s_axi_arprot};

always @(posedge s_axi_aclk) begin
    if (!s_axi_aresetn) begin
        aw_stored     <= 1'b0;
        awaddr_stored <= {C_S_AXI_ADDR_WIDTH{1'b0}};
        w_stored      <= 1'b0;
        wdata_stored  <= 32'h0000_0000;
        wstrb_stored  <= 4'b0000;
        s_axi_bresp   <= AXI_RESP_OKAY;
        s_axi_bvalid  <= 1'b0;
    end else begin
        // Capture Write Address independently.
        if (s_axi_awready && s_axi_awvalid) begin
            aw_stored     <= 1'b1;
            awaddr_stored <= s_axi_awaddr;
        end

        // Capture Write Data independently.
        if (s_axi_wready && s_axi_wvalid) begin
            w_stored     <= 1'b1;
            wdata_stored <= s_axi_wdata;
            wstrb_stored <= s_axi_wstrb;
        end

        // Once both parts exist, pulse wr_en through write_commit
        // and create the AXI B response.
        if (write_commit) begin
            aw_stored    <= 1'b0;
            w_stored     <= 1'b0;
            s_axi_bresp  <= AXI_RESP_OKAY;
            s_axi_bvalid <= 1'b1;
        end else if (s_axi_bvalid && s_axi_bready) begin
            s_axi_bvalid <= 1'b0;
        end
    end
end

always @(posedge s_axi_aclk) begin
    if (!s_axi_aresetn) begin
        s_axi_rdata  <= 32'h0000_0000;
        s_axi_rresp  <= AXI_RESP_OKAY;
        s_axi_rvalid <= 1'b0;
    end else begin
        // Capture the selected register value at AR handshake.
        if (s_axi_arready && s_axi_arvalid) begin
            s_axi_rdata  <= rd_data;
            s_axi_rresp  <= AXI_RESP_OKAY;
            s_axi_rvalid <= 1'b1;
        end else if (s_axi_rvalid && s_axi_rready) begin
            s_axi_rvalid <= 1'b0;
        end
    end
end

endmodule
reference_rtl/custom_register_bank.v · Verilog
module custom_register_bank (
    input  wire        clk,
    input  wire        resetn,

    // Bus-independent register access interface.
    // SoC 12 will connect this interface to AXI4-Lite.
    input  wire        wr_en,
    input  wire [7:0]  wr_offset,
    input  wire [31:0] wr_data,
    input  wire [3:0]  wr_strb,

    input  wire [7:0]  rd_offset,
    output reg  [31:0] rd_data,

    // Hardware status / event inputs
    input  wire        busy_i,
    input  wire        done_i,
    input  wire        error_i,
    input  wire        irq_done_event_i,
    input  wire        irq_error_event_i,
    input  wire [31:0] data_out_i,

    // Control outputs
    output reg         enable_o,
    output reg  [1:0]  mode_o,
    output reg         start_pulse_o,
    output reg         clear_pulse_o,
    output reg  [31:0] data_in_o,
    output reg  [1:0]  irq_status_o
);

localparam [7:0] REG_CONTROL    = 8'h00;
localparam [7:0] REG_STATUS     = 8'h04;
localparam [7:0] REG_COMMAND    = 8'h08;
localparam [7:0] REG_IRQ_STATUS = 8'h0C;
localparam [7:0] REG_DATA_IN    = 8'h10;
localparam [7:0] REG_DATA_OUT   = 8'h14;
localparam [7:0] REG_VERSION    = 8'h18;
localparam [7:0] REG_ID         = 8'h1C;

localparam [31:0] VERSION_VALUE = 32'h0001_0000;
localparam [31:0] ID_VALUE      = 32'h524D_4150; // ASCII "RMAP"

integer byte_index;

always @(posedge clk) begin
    if (!resetn) begin
        enable_o      <= 1'b0;
        mode_o        <= 2'b00;
        start_pulse_o <= 1'b0;
        clear_pulse_o <= 1'b0;
        data_in_o     <= 32'h0000_0000;
        irq_status_o  <= 2'b00;
    end else begin
        // W1P pulses are one clock wide by default.
        start_pulse_o <= 1'b0;
        clear_pulse_o <= 1'b0;

        // Hardware events set IRQ status.
        // Event set has priority over software clear in the same cycle.
        if (irq_done_event_i) begin
            irq_status_o[0] <= 1'b1;
        end else if (
            wr_en &&
            (wr_offset == REG_IRQ_STATUS) &&
            wr_strb[0] &&
            wr_data[0]
        ) begin
            irq_status_o[0] <= 1'b0;
        end

        if (irq_error_event_i) begin
            irq_status_o[1] <= 1'b1;
        end else if (
            wr_en &&
            (wr_offset == REG_IRQ_STATUS) &&
            wr_strb[0] &&
            wr_data[1]
        ) begin
            irq_status_o[1] <= 1'b0;
        end

        if (wr_en) begin
            case (wr_offset)
                REG_CONTROL: begin
                    if (wr_strb[0]) begin
                        enable_o <= wr_data[0];
                        mode_o   <= wr_data[2:1];
                    end
                end

                REG_COMMAND: begin
                    if (wr_strb[0]) begin
                        start_pulse_o <= wr_data[0];
                        clear_pulse_o <= wr_data[1];
                    end
                end

                REG_DATA_IN: begin
                    // Byte-enable write using WSTRB-equivalent strobes.
                    for (byte_index = 0; byte_index < 4; byte_index = byte_index + 1) begin
                        if (wr_strb[byte_index]) begin
                            data_in_o[byte_index*8 +: 8] <=
                                wr_data[byte_index*8 +: 8];
                        end
                    end
                end

                default: begin
                    // RO / reserved / unmapped writes have no effect.
                end
            endcase
        end
    end
end

always @(*) begin
    case (rd_offset)
        REG_CONTROL: begin
            rd_data = {29'h0, mode_o, enable_o};
        end

        REG_STATUS: begin
            rd_data = {29'h0, error_i, done_i, busy_i};
        end

        REG_COMMAND: begin
            // W1P command register has no retained state.
            rd_data = 32'h0000_0000;
        end

        REG_IRQ_STATUS: begin
            rd_data = {30'h0, irq_status_o};
        end

        REG_DATA_IN: begin
            rd_data = data_in_o;
        end

        REG_DATA_OUT: begin
            rd_data = data_out_i;
        end

        REG_VERSION: begin
            rd_data = VERSION_VALUE;
        end

        REG_ID: begin
            rd_data = ID_VALUE;
        end

        default: begin
            rd_data = 32'h0000_0000;
        end
    endcase
end

endmodule

어댑터의 주소 폭은 기본 32비트이고 실제 레지스터 선택에는 하위 8비트만 사용됩니다. bank는 AXI 핸드셰이크를 직접 처리하지 않고 wr_en과 wr_offset/wr_data/wr_strb를 사용합니다. 읽기는 rd_offset에 따른 조합 rd_data이며 어댑터가 AR 수락 시 값을 저장합니다.

02다섯 채널과 시간 계약

채널payload수락 조건
AW (쓰기 주소)AWADDR, AWPROTAWVALID && AWREADY
W (쓰기 데이터)WDATA, WSTRBWVALID && WREADY
B (쓰기 응답)BRESPBVALID && BREADY
AR (읽기 주소)ARADDR, ARPROTARVALID && ARREADY
R (읽기 데이터)RDATA, RRESPRVALID && RREADY

AW와 W는 서로 다른 상승 에지에서 수락될 수 있습니다. aw_stored와 w_stored가 모두 1이 된 뒤 write_commit이 활성화되고 다음 상승 에지에서 bank에 쓰기가 반영됩니다. 이때 두 저장 플래그를 지우고 BVALID를 올립니다. BREADY=0이면 BVALID와 BRESP를 보존하며 새 AW/W를 수락하지 않습니다. AR은 독립적으로 진행할 수 있고 RVALID가 대기하는 동안 새 AR을 수락하지 않습니다.

상승 에지AW 먼저W 먼저동시 도착
E0AW 수락W 수락AW/W 수락
E1대기대기commit·B 생성
E2W 수락(예시)AW 수락(예시)B 대기 또는 수락
E3commit·B 생성commit·B 생성이전 응답 종료 후 새 거래

표의 commit은 해당 상승 에지에서 wr_en을 bank가 샘플링하는 사건이며 응답은 에지 이후 관찰됩니다. E2의 두 번째 수락 시점은 설명을 위한 예시입니다. TB는 하강 에지에 입력을 변경하며 모니터는 상승 에지의 핸드셰이크를 집계합니다.

RO(알오, 읽기 전용), W1P(더블유원피, 1 쓰기 펄스), W1C(더블유원씨, 1 쓰기 해제)를 구분합니다. COMMAND와 IRQ의 실제 펄스·이벤트 경합은 이 장의 시험 범위에 포함되지 않습니다.

바이트3 [31:24]2 [23:16]1 [15:8]0 [7:0]
기존11223344
새 데이터AABBCCDD
WSTRB=01010101
결과11BB33DD

WSTRB(라이트 스트로브, 바이트 쓰기 활성 신호)가 0인 바이트는 기존 값이 유지됩니다. 0000은 레지스터 변화가 없어도 이 어댑터에서는 정상 쓰기 거래와 OKAY 응답을 생성합니다. 미매핑 쓰기와 RO 쓰기는 무시되며 미매핑 읽기는 0, 응답은 OKAY입니다. 이는 이 구현의 정책이지 모든 AXI 슬레이브의 일반 규칙이 아닙니다. 주소 0x110은 하위 8비트 0x10으로 해석됩니다. 상위 주소 디코딩은 외부 시스템에서 담당해야 합니다.

04검증 시나리오와 독립 판정

시험주요 자극기대
T1AW → W, 전체 쓰기DATA_IN 11223344
T2W → AW, WSTRB 0101DATA_IN 11BB33DD
T3CONTROL 쓰기 및 VERSION/ID 읽기enable=1, mode=2, 상수 유지
T4동시 AW/W, WSTRB 0000, RO/미매핑 쓰기, 별칭·DATA_OUT 읽기기존 값 유지, 0xFC 읽기 0, 0x110 별칭
T5B/R 대기 상태에서 reset응답 취소·CONTROL/DATA_IN 초기화

수락된 AWADDR와 WDATA/WSTRB를 각각 saved_aw, saved_w, saved_strb에 저장하고 실제 wr_en 에지에서 비교합니다. 수락 후 live 입력을 일부러 변경하므로 저장 로직 없이 현재 버스값을 쓰는 결함을 검출할 수 있습니다. 읽기 주소도 수락 뒤 변경하여 RDATA가 조합 rd_data를 그대로 따라가는 결함을 확인합니다. 대기 중 응답 코드와 valid도 검사합니다.

T5는 마지막 쓰기 commit 이후 B 응답을 받지 않은 상태에서 AR을 수락시킵니다. BVALID와 RVALID가 모두 1인 것을 확인한 후 resetn을 낮춥니다. 동기 리셋 이후 응답과 저장 상태가 초기화되어야 합니다. 이때 완료되지 않은 B/R은 정상 응답 수에 포함하지 않습니다.

`timescale 1ns/1ps
// 제15장: 기존 AXI4-Lite 어댑터 + 레지스터 뱅크를 읽기 전용 DUT로 검증.
// AW/W 독립 수락, B/R 대기 유지, WSTRB 부분 쓰기, Reset을 자동 판정한다.
module tb_axi4lite_registers;
    reg clk=0, resetn=0;
    always #5 clk=~clk;
    reg [31:0] awaddr=0, wdata=0, araddr=0;
    reg [3:0] wstrb=0;
    reg awvalid=0, wvalid=0, bready=0, arvalid=0, rready=0;
    wire awready,wready,bvalid,arready,rvalid;
    wire [1:0] bresp,rresp;
    wire [31:0] rdata;
    wire wr_en;
    wire [7:0] wr_offset,rd_offset;
    wire [31:0] wr_data,rd_data;
    wire [3:0] wr_strb;
    wire enable_o,start_pulse_o,clear_pulse_o;
    wire [1:0] mode_o,irq_status_o;
    wire [31:0] data_in_o;
    integer checks=0, commits=0;
    integer aw_count=0, w_count=0, b_count=0, ar_count=0, r_count=0;
    reg [31:0] saved_aw, saved_w;
    reg [3:0] saved_strb;
    reg [31:0] captured;

    axi4lite_slave_adapter dut (
        .s_axi_aclk(clk), .s_axi_aresetn(resetn),
        .s_axi_awaddr(awaddr), .s_axi_awprot(3'b0),
        .s_axi_awvalid(awvalid), .s_axi_awready(awready),
        .s_axi_wdata(wdata), .s_axi_wstrb(wstrb),
        .s_axi_wvalid(wvalid), .s_axi_wready(wready),
        .s_axi_bresp(bresp), .s_axi_bvalid(bvalid), .s_axi_bready(bready),
        .s_axi_araddr(araddr), .s_axi_arprot(3'b0),
        .s_axi_arvalid(arvalid), .s_axi_arready(arready),
        .s_axi_rdata(rdata), .s_axi_rresp(rresp),
        .s_axi_rvalid(rvalid), .s_axi_rready(rready),
        .wr_en(wr_en), .wr_offset(wr_offset), .wr_data(wr_data),
        .wr_strb(wr_strb), .rd_offset(rd_offset), .rd_data(rd_data)
    );
    custom_register_bank bank (
        .clk(clk), .resetn(resetn), .wr_en(wr_en),
        .wr_offset(wr_offset), .wr_data(wr_data), .wr_strb(wr_strb),
        .rd_offset(rd_offset), .rd_data(rd_data),
        .busy_i(1'b0), .done_i(1'b0), .error_i(1'b0),
        .irq_done_event_i(1'b0), .irq_error_event_i(1'b0),
        .data_out_i(32'h12345678), .enable_o(enable_o),
        .mode_o(mode_o), .start_pulse_o(start_pulse_o),
        .clear_pulse_o(clear_pulse_o), .data_in_o(data_in_o),
        .irq_status_o(irq_status_o)
    );
    // (추가) 실제 수락 및 저장된 payload를 BFM과 독립적으로 검증.
    always @(posedge clk) if(resetn) begin
        if(wr_en === 1'b1) begin
            if(aw_count!=commits+1 || w_count!=commits+1 ||
               wr_offset !== saved_aw[7:0] || wr_data !== saved_w ||
               wr_strb !== saved_strb)
                $fatal(1,"FAIL COMMIT_CONTRACT");
            commits++;
        end
        if(awvalid && awready) begin
            aw_count++; saved_aw=awaddr;
        end
        if(wvalid && wready) begin
            w_count++; saved_w=wdata; saved_strb=wstrb;
        end
        if(bvalid && bready) begin
            if(bresp !== 2'b00 || b_count>=commits)
                $fatal(1,"FAIL B_TRANSACTION");
            b_count++;
        end
        if(arvalid && arready) ar_count++;
        if(rvalid && rready) begin
            if(rresp !== 2'b00 || r_count>=ar_count)
                $fatal(1,"FAIL R_TRANSACTION");
            r_count++;
        end
    end

    task automatic send_aw(input [31:0] address);
        integer guard;
        begin
            @(negedge clk);
            awaddr=address; awvalid=1;
            guard=0;
            while(awready !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if(guard>100) $fatal(1,"FAIL AW_TIMEOUT");
            end
            @(posedge clk);
            @(negedge clk);
            awvalid=0;
            // (추가) 수락 이후 주소를 바꿔 저장 여부를 검증한다.
            awaddr=32'h000000FC;
        end
    endtask

    task automatic send_w(input [31:0] data,input [3:0] strobe);
        integer guard;
        begin
            @(negedge clk);
            wdata=data; wstrb=strobe; wvalid=1;
            guard=0;
            while(wready !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if(guard>100) $fatal(1,"FAIL W_TIMEOUT");
            end
            @(posedge clk);
            @(negedge clk);
            wvalid=0;
            // (추가) 수락 이후 live 데이터와 스트로브를 변경한다.
            wdata=32'hDEADBEEF; wstrb=4'b0000;
        end
    endtask

    task automatic finish_b;
        integer guard;
        begin
            guard=0;
            while(bvalid !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if(guard>100) $fatal(1,"FAIL B_TIMEOUT");
            end
            if(bresp !== 2'b00) $fatal(1,"FAIL BRESP");
            // 응답을 받지 않는 동안 BVALID는 내려가면 안 된다.
            repeat(3) begin
                @(negedge clk);
                if(bvalid !== 1'b1 || bresp !== 2'b00 || awready !== 1'b0 ||
                   wready !== 1'b0) $fatal(1,"FAIL B_HOLD");
            end
            bready=1;
            @(posedge clk);
            @(negedge clk);
            bready=0;
            if(bvalid !== 1'b0) $fatal(1,"FAIL B_CLEAR");
            checks=checks+1;
        end
    endtask

    task automatic read_expect(input [31:0] address,input [31:0] expected);
        integer guard;
        begin
            @(negedge clk);
            araddr=address; arvalid=1;
            guard=0;
            while(arready !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if(guard>100) $fatal(1,"FAIL AR_TIMEOUT");
            end
            @(posedge clk);
            @(negedge clk);
            arvalid=0;
            if(rvalid !== 1'b1 || rresp !== 2'b00 || rdata !== expected)
                $fatal(1,"FAIL READ addr=%h got=%h exp=%h",address,rdata,expected);
            captured=rdata;
            // (추가) 다른 주소를 제시해도 캡처한 R payload는 유지되어야 한다.
            araddr=(address[7:0]==8'h18)?32'h1C:32'h18;
            repeat(3) begin
                @(negedge clk);
                if(rvalid !== 1'b1 || rresp !== 2'b00 || arready !== 1'b0 ||
                   rdata !== captured) $fatal(1,"FAIL R_HOLD");
            end
            rready=1;
            @(posedge clk);
            @(negedge clk);
            rready=0;
            if(rvalid !== 1'b0) $fatal(1,"FAIL R_CLEAR");
            checks=checks+1;
        end
    endtask

    initial begin
        #20000;
        $fatal(1,"FAIL GLOBAL_TIMEOUT");
    end

`ifdef VCD
    initial begin
        $dumpfile("ch15_axi4lite.vcd");
        $dumpvars(0,tb_axi4lite_registers);
    end
`endif
    initial begin
        repeat(4) @(negedge clk);
        if(awready !== 1'b0 || wready !== 1'b0 ||
           arready !== 1'b0) $fatal(1,"FAIL RESET_READY");
        resetn=1;
        @(negedge clk);

        // T1: AW를 먼저 보내고 W가 오기 전에는 commit하지 않는다.
        send_aw(32'h10);
        repeat(3) @(negedge clk);
        if(commits!=0 || bvalid !== 1'b0) $fatal(1,"FAIL AW_ONLY");
        send_w(32'h11223344,4'b1111);
        finish_b();
        read_expect(32'h10,32'h11223344);
        $display("T1_AW_BEFORE_W_PASS");

        // T2: W를 먼저 보내도 독립 버퍼에 보관된다.
        send_w(32'hAABBCCDD,4'b0101);
        repeat(3) @(negedge clk);
        if(commits!=1 || bvalid !== 1'b0) $fatal(1,"FAIL W_ONLY");
        send_aw(32'h10);
        finish_b();
        read_expect(32'h10,32'h11BB33DD);
        $display("T2_W_BEFORE_AW_WSTRB_PASS");

        // T3: CONTROL, VERSION, ID 및 읽기 응답 유지.
        send_aw(32'h00);
        send_w(32'h00000005,4'b0001);
        finish_b();
        read_expect(32'h00,32'h00000005);
        read_expect(32'h18,32'h00010000);
        read_expect(32'h1C,32'h524D4150);
        if(enable_o !== 1'b1 || mode_o !== 2'b10)
            $fatal(1,"FAIL CONTROL_OUTPUT");
        $display("T3_CONTROL_RO_PASS");

        // (추가) T4: 동시 AW/W, zero strobe, RO 및 미매핑 쓰기.
        fork
            send_aw(32'h10);
            send_w(32'hFFFFFFFF,4'b0000);
        join
        finish_b();
        read_expect(32'h10,32'h11BB33DD);
        send_aw(32'h18); send_w(32'hFFFFFFFF,4'b1111);
        finish_b();
        read_expect(32'h18,32'h00010000);
        send_aw(32'hFC); send_w(32'hFFFFFFFF,4'b1111);
        finish_b();
        read_expect(32'hFC,32'h00000000);
        read_expect(32'h110,32'h11BB33DD); // 하위 8비트 주소 별칭
        read_expect(32'h14,32'h12345678);
        $display("T4_ZERO_RO_ALIAS_PASS");

        // (변경) T5: B/R 응답이 실제로 대기 중일 때 리셋.
        send_aw(32'h00); send_w(32'h00000007,4'b0001);
        @(negedge clk);
        if(bvalid !== 1'b1 || bresp !== 2'b00 || enable_o !== 1'b1 ||
           mode_o !== 2'b11 || data_in_o !== 32'h11BB33DD)
            $fatal(1,"FAIL RESET_B_PRECONDITION");
        araddr=32'h10; arvalid=1;
        @(posedge clk);
        @(negedge clk); arvalid=0;
        if(rvalid !== 1'b1 || rdata !== 32'h11BB33DD || bvalid !== 1'b1)
            $fatal(1,"FAIL RESET_R_PRECONDITION");
        resetn=0;
        repeat(3) @(negedge clk);
        if(bvalid !== 1'b0 || rvalid !== 1'b0 ||
           enable_o !== 1'b0 || data_in_o !== 32'b0)
            $fatal(1,"FAIL RESET_CLEAR");
        resetn=1;
        @(negedge clk);
        read_expect(32'h10,32'h00000000);
        read_expect(32'h00,32'h00000000);
        if(commits!=7 || checks!=18 || aw_count!=7 || w_count!=7 ||
           b_count!=6 || ar_count!=13 || r_count!=12)
            $fatal(1,"FAIL COUNTS commits=%0d checks=%0d",commits,checks);
        $display("T5_RESET_PENDING_PASS");
        $display("PASS CH15 commits=%0d checks=%0d",commits,checks);
        $finish;
    end
endmodule
코드역할
send_aw / send_w주소와 데이터의 독립 구동·수락 후 입력 변경
fork ... join동시 AW/W 구동
always @(posedge clk)채널 수락 및 실제 쓰기 commit 독립 집계
saved_aw / saved_w / saved_strb수락된 입력의 기대 payload 보존
finish_bB 응답 및 대기 중 유지 확인
read_expectR 응답값·코드·대기 유지 검사
RESET_B/R_PRECONDITION실제 응답이 대기 중인지 확인
checks / commits / *_count전체 시험 완료 및 누락 검출

commit 7회 중 마지막 B 응답은 리셋으로 취소됩니다. AR 13회 중 마지막 리셋 전 읽기의 R 응답도 취소됩니다. 따라서 완료된 B 6회와 R 12회로 총 18개 checks가 됩니다. 카운터는 테스트 전체의 관찰 기록이므로 DUT 리셋에서 초기화하지 않습니다.

Icarus 대체 실행

scripts/run_ch15.sh · Bash
#!/usr/bin/env bash
# 사용: bash scripts/run_ch15.sh
# 원본 RTL은 읽기 전용; 시뮬레이션 산출물은 .build/ch15에만 생성한다.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
RTL="${RTL_DIR:-$ROOT/reference_rtl}"
for f in axi4lite_slave_adapter.v custom_register_bank.v; do
  if [[ ! -f "$RTL/$f" ]]; then
    echo "NOT_RUN: missing $RTL/$f" >&2
    exit 2
  fi
done
if ! command -v iverilog >/dev/null 2>&1 || ! command -v vvp >/dev/null 2>&1; then
  echo "NOT_RUN: Icarus Verilog not installed" >&2
  exit 2
fi
RTL="$(realpath "$RTL")"
mkdir -p "$ROOT/.build/ch15"
cd "$ROOT/.build/ch15"
iverilog -g2012 -DVCD -s tb_axi4lite_registers -o sim \
  "$RTL/axi4lite_slave_adapter.v" "$RTL/custom_register_bank.v" \
  "$ROOT/tb/ch15/tb_axi4lite_registers.sv"
vvp sim | tee simulation.log
grep -Fxq 'PASS CH15 commits=7 checks=18' simulation.log
