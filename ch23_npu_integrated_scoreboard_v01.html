제23장 · NPU 통합 정답 비교

실제 4뉴런 NPU의 점수·클래스·지연·오류를 독립 참조 모델로 검증합니다.

PART 06 · CHAPTER 231교시 60분 + 2교시 60분원본 RTL 변경 없음

00개요 · 통합 NPU의 정답을 어떻게 확인하는가

제23장은 이미 완성된 npu_engine4를 DUT(검증 대상 회로)로 사용합니다. 입력 벡터와 네 뉴런의 가중치를 BRAM 형태의 배열에 적재한 다음, 각 뉴런의 MAC(맥, 곱셈 누산) 결과와 편향을 합산하고 가장 높은 점수를 class_o로 선택하는 실제 동작을 검증합니다. 단순히 결과가 나오는지 확인하는 수준을 넘어 독립 참조 모델, 지연 시간, 경계 조건, 오류 신호를 검사합니다.

1교시 · 60분0~20분 원본 RTL 구조 / 20~40분 수학 모델 / 40~60분 지연·경계조건
2교시 · 60분60~95분 전체 TB / 95~110분 실행 / 110~120분 오류 분석

011교시 ① · 원본 포트와 시간 계약 (0~20분)

npu_engine4의 clk는 상승 에지 동기식이고 resetn은 active-low 동기 리셋입니다. start_i가 유효할 때 length_i 길이의 데이터를 처리합니다. load_ready_o가 1일 때만 x_wr_en, w_wr_en, b_wr_en을 통해 입력·가중치·편향을 적재합니다. scores_o는 41비트 점수 네 개를 묶은 164비트이고, class_o는 2비트 클래스 번호입니다.

신호폭검증 계약
length_i71~64, 필요한 주소 데이터가 모두 적재되어야 시작 가능
data_i16 signed입력 벡터와 뉴런별 가중치
bias_i40 signed뉴런별 편향
scores_o16441비트 점수 × 4, 하위 41비트는 뉴런 0
done_o1정상 처리 완료 시 1클록 펄스
error_o1누락된 입력으로 시작하면 오류 펄스

021교시 ② · 독립 정수 모델과 분류 (20~40분)

뉴런 n의 정답은 score[n] = bias[n] + Σ(x[k] × w[n][k])입니다. 예를 들어 입력이 [1, −1]이고 뉴런 0의 가중치가 [1, 1]이면 점수는 0입니다. 같은 입력에 뉴런 1의 가중치가 [1, −1]이면 점수는 2입니다. 모델은 DUT 내부 acc0~acc3를 참조하지 않고 TB의 model_x, model_w, model_bias만으로 계산합니다.

최댓값을 찾을 때 원본은 >만 사용합니다. 따라서 동점이면 먼저 발견한 낮은 뉴런 번호가 유지됩니다. 모든 점수는 부호 있는 41비트로 비교하며 scores_o[n*41+:41]을 각각 확인합니다. 16비트 입력의 곱은 32비트, 누산기는 40비트, 편향 포함 최종 점수는 41비트입니다.

031교시 ③ · 파이프라인과 경계조건 (40~60분)

원본의 상태 전이는 IDLE → READ → ISSUE → ... → DRAIN1 → DRAIN2 → IDLE입니다. READ에서 메모리 값을 레지스터로 읽고, ISSUE에서 곱셈 입력을 등록합니다. 마지막 입력 이후 두 개의 drain 상태를 거쳐 누산 결과가 scores_o에 기록됩니다. 시작을 수락한 상승 에지 다음부터 done_o가 관찰되는 에지까지는 2×length+3 클록입니다. 이는 이 RTL 구현의 계약이지 모든 NPU에 공통되는 공식은 아닙니다.

정상 길이 1·2, 네 클래스, 편향 변경을 비교하고, 아직 세 번째 주소에 데이터를 적재하지 않은 상태에서 길이 3을 시작해 error_o가 발생하는지 확인합니다. 데이터 누락 오류는 MAC 정답 오류와 구분합니다.

042교시 ① · 전체 SystemVerilog 테스트벤치 (60~95분)

아래 코드는 별도 참조 배열을 만들고 6개의 정상 연산과 1개의 오류 시나리오를 자동 검사합니다. $fatal이 실행되면 시뮬레이션은 실패합니다. 원본 NPU/DSP 모듈은 변경하지 않습니다.

tb/ch23/tb_npu_integrated.sv · SystemVerilog · 신규 TB · 전체 코드
`timescale 1ns/1ps
// 제23장: 원본 npu_engine4 + DSP lane + multiplier 통합 검증.
// 정답은 DUT 내부 누산기가 아니라 독립 integer 참조 모델로 계산한다.
module tb_npu_integrated;
    reg clk=0, resetn=0, start_i=0;
    reg [6:0] length_i=0;
    reg x_wr_en=0, w_wr_en=0, b_wr_en=0;
    reg [5:0] addr_i=0;
    reg [1:0] neuron_i=0;
    reg signed [15:0] data_i=0;
    reg signed [39:0] bias_i=0;
    wire load_ready_o, busy_o, done_o, error_o;
    wire [1:0] class_o;
    wire [163:0] scores_o;

    // 원본 포트와 폭을 그대로 연결한다.
    npu_engine4 dut (
        .clk(clk), .resetn(resetn), .start_i(start_i),
        .length_i(length_i), .x_wr_en(x_wr_en),
        .w_wr_en(w_wr_en), .b_wr_en(b_wr_en),
        .addr_i(addr_i), .neuron_i(neuron_i),
        .data_i(data_i), .bias_i(bias_i),
        .load_ready_o(load_ready_o), .busy_o(busy_o),
        .done_o(done_o), .error_o(error_o),
        .class_o(class_o), .scores_o(scores_o)
    );
    always #5 clk=~clk;

    // TB 전용 입력/가중치/편향 복제본: DUT 내부 메모리 참조 금지.
    integer model_x[0:63];
    integer model_w[0:3][0:63];
    reg signed [39:0] model_bias[0:3];
    reg signed [40:0] expected[0:3];
    integer i,j,cycles,tests=0;
    reg [1:0] expected_class;
    reg signed [40:0] best;

    task automatic load_x(input [5:0] addr, input signed [15:0] value);
        begin
            @(negedge clk);
            if (load_ready_o !== 1'b1) $fatal(1,"FAIL LOAD_X_READY");
            addr_i=addr; data_i=value; x_wr_en=1;
            @(negedge clk);
            x_wr_en=0; model_x[addr]=value;
        end
    endtask

    task automatic load_w(input [1:0] neuron, input [5:0] addr,
                          input signed [15:0] value);
        begin
            @(negedge clk);
            if (load_ready_o !== 1'b1) $fatal(1,"FAIL LOAD_W_READY");
            neuron_i=neuron; addr_i=addr; data_i=value; w_wr_en=1;
            @(negedge clk);
            w_wr_en=0; model_w[neuron][addr]=value;
        end
    endtask

    task automatic load_bias(input [1:0] neuron,
                             input signed [39:0] value);
        begin
            @(negedge clk);
            neuron_i=neuron; bias_i=value; b_wr_en=1;
            @(negedge clk);
            b_wr_en=0; model_bias[neuron]=value;
        end
    endtask

    // 4개 뉴런의 signed 곱-누산 + bias를 별도로 계산한다.
    // 동점이면 낮은 뉴런 번호를 선택한다(원본의 > 비교 계약).
    task automatic calculate(input integer len);
        integer n,k;
        reg signed [40:0] acc;
        begin
            for(n=0;n<4;n=n+1) begin
                acc=$signed(model_bias[n]);
                for(k=0;k<len;k=k+1)
                    acc=acc+$signed(model_x[k])*$signed(model_w[n][k]);
                expected[n]=acc;
            end
            expected_class=0;
            best=expected[0];
            for(n=1;n<4;n=n+1)
                if(expected[n]>best) begin
                    best=expected[n];
                    expected_class=n;
                end
        end
    endtask

    // 시작 에지를 0으로 세고 done_o가 올라오는 에지까지 측정.
    // 원본 FSM: READ/ISSUE 각각 len회, DRAIN1/2 이후 done.
    // done 관측 지연: 2*len+3 클록(시작 에지 제외).
    task automatic execute(input integer len);
        integer n;
        begin
            calculate(len);
            @(negedge clk);
            if(load_ready_o !== 1'b1) $fatal(1,"FAIL NOT_IDLE");
            length_i=len; start_i=1;
            @(posedge clk);
            #1;
            if(busy_o !== 1'b1) $fatal(1,"FAIL BUSY_START");
            @(negedge clk);
            start_i=0;
            cycles=0;
            while(done_o !== 1'b1) begin
                @(posedge clk);
                #1;
                cycles=cycles+1;
                if(cycles>2*len+10) $fatal(1,"FAIL DONE_TIMEOUT");
            end
            if(cycles != 2*len+3)
                $fatal(1,"FAIL LATENCY got=%0d expected=%0d",cycles,2*len+3);
            if(busy_o !== 1'b0 || error_o !== 1'b0 ||
               class_o !== expected_class)
                $fatal(1,"FAIL STATUS_CLASS got=%0d expected=%0d",
                       class_o,expected_class);
            for(n=0;n<4;n=n+1)
                if($signed(scores_o[n*41+:41]) !== expected[n])
                    $fatal(1,"FAIL SCORE neuron=%0d got=%0d expected=%0d",
                           n,$signed(scores_o[n*41+:41]),expected[n]);
            tests=tests+1;
            $display("CHECK len=%0d cycles=%0d class=%0d",len,cycles,class_o);
            @(posedge clk);
            #1;
            if(done_o !== 1'b0) $fatal(1,"FAIL DONE_NOT_PULSE");
        end
    endtask

    initial begin
        #1000000;
        $fatal(1,"FAIL GLOBAL_TIMEOUT");
    end

    initial begin
        $dumpfile("ch23_npu_integrated.vcd");
        $dumpvars(0,tb_npu_integrated);
        repeat(5) @(negedge clk);
        resetn=1;
        // 길이 2, 음수 가중치, 네 클래스의 독립 정답 비교.
        for(i=0;i<4;i=i+1) begin
            model_bias[i]=0;
            load_w(i,0,(i&2)?-16'sd1:16'sd1);
            load_w(i,1,(i&1)?-16'sd1:16'sd1);
        end
        for(j=0;j<4;j=j+1) begin
            load_x(0,(j&2)?-16'sd1:16'sd1);
            load_x(1,(j&1)?-16'sd1:16'sd1);
            execute(2);
            if(class_o !== j[1:0]) $fatal(1,"FAIL CLASS_CASE %0d",j);
        end
        // 편향은 누산 결과에 더해지며 뉴런 3이 우승한다.
        load_x(0,16'sd1); load_x(1,16'sd1);
        load_bias(3,40'sd10);
        execute(2);
        if(class_o !== 2'd3) $fatal(1,"FAIL BIAS_CLASS");
        // 길이 1: 남은 유효 가중치에 대한 결과만 비교.
        execute(1);
        // 길이 3: 세 번째 입력이 없어 오류, busy/done 미발생.
        @(negedge clk);
        length_i=3; start_i=1;
        @(posedge clk); #1;
        if(error_o !== 1'b1 || busy_o !== 1'b0 || done_o !== 1'b0)
            $fatal(1,"FAIL INVALID_LENGTH");
        @(negedge clk);
        start_i=0;
        $display("PASS CH23 cases=%0d invalid_length=1",tests);
        $finish;
    end
endmodule

코드 풀이 — 핵심 구문

calculate()는 입력과 가중치를 독립 배열에서 읽어 기대 점수와 클래스를 계산합니다. execute()는 시작 신호를 한 클록 제시하고 done_o까지의 클록을 셉니다. $signed(scores_o[n*41+:41]) !== expected[n]는 실제 점수와 독립 모델을 4상태 비교합니다. load_x()와 load_w()는 load_ready_o를 확인해 유효한 적재만 수행합니다.

052교시 ② · 실행과 예상 출력 (95~110분)

Ubuntu 터미널에서 bash scripts/run_ch23.sh를 실행합니다. 스크립트는 Icarus Verilog(아이베릴로그, RTL 시뮬레이터)를 이용해 원본 npu_engine4, npu_dsp_mac_lane, dsp_multiplier와 TB를 컴파일합니다. 원본 RTL은 읽기 전용이며 파형과 로그는 .build/ch23에 저장합니다.

scripts/run_ch23.sh · Bash · 신규 실행 스크립트 · 전체 코드
#!/usr/bin/env bash
# 제23장: 원본 NPU/DSP RTL을 읽기 전용으로 컴파일하고 결과를 .build에 저장.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
RTL="${RTL_DIR:-$ROOT/reference_rtl}"
if ! command -v iverilog >/dev/null 2>&1 || ! command -v vvp >/dev/null 2>&1; then
  echo "NOT_RUN: iverilog 또는 vvp 없음" >&2
  exit 2
fi
for name in npu_engine4.v npu_dsp_mac_lane.v dsp_multiplier.v; do
  if [[ ! -f "$RTL/$name" ]]; then
    echo "NOT_RUN: RTL 파일 없음: $RTL/$name" >&2
    exit 2
  fi
done
mkdir -p "$ROOT/.build/ch23"
cd "$ROOT/.build/ch23"
iverilog -g2012 -s tb_npu_integrated -o sim \
  "$RTL/npu_engine4.v" "$RTL/npu_dsp_mac_lane.v" \
  "$RTL/dsp_multiplier.v" "$ROOT/tb/ch23/tb_npu_integrated.sv"
vvp sim | tee simulation.log
grep -q '^PASS CH23 cases=6 invalid_length=1$' simulation.log
