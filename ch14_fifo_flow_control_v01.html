00개요 · FIFO의 저장과 흐름 제어

제13장의 조합형 UART Echo는 데이터를 보관하지 않았습니다. 제14장은 실제 uart_core에 구현된 깊이 16바이트 RX/TX FIFO를 검증합니다. FIFO(피포, 먼저 들어온 데이터가 먼저 나오는 버퍼)는 송수신 속도 차이를 흡수합니다. ready/valid는 전송 가능 여부와 데이터 유효 여부를 나타냅니다.

1교시 60분0~20분 실제 포트 / 20~40분 full·empty / 40~60분 backpressure·동시 push/pop
2교시 60분60~90분 TB 전체 코드 / 90~105분 실행 / 105~120분 파형·오류 점검

011교시 ① · 실제 RTL의 포트와 구조 (0~20분)

원본 uart_core는 uart_rx와 uart_tx를 포함하며 각각의 16바이트 FIFO를 사용합니다. RX는 rx_out_data/rx_out_valid/rx_out_ready, TX는 tx_in_data/tx_in_valid/tx_in_ready를 제공합니다. rx_framing_error_o와 rx_overrun_o는 UART 수신 측 오류 상태입니다. full/empty 전용 외부 출력 포트는 없습니다. FIFO 상태는 rx_count와 tx_count를 통해 내부적으로 관리합니다.

이 장에서는 CLK_HZ=1000000, BAUD=100000으로 설정해 한 비트를 10클록으로 줄여 시뮬레이션합니다. 실제 보드의 100MHz/115200bps 설정과 구분합니다.

021교시 ② · Empty·Full·동시 Push/Pop (20~40분)

상태조건의미
Emptyrx_count==0읽을 RX 바이트가 없으므로 rx_out_valid=0
Fulltx_count==16TX FIFO 저장 공간이 가득 참
Pushtx_in_valid && tx_in_ready상승 에지에서 TX 데이터 수락
Popphy_tx_valid && phy_tx_readyTX FIFO 데이터를 UART 송신기로 전달

원본은 FIFO가 가득 차도 같은 에지에 Pop이 일어나면 Push를 허용합니다. 즉 tx_in_ready = resetn && ((tx_count<16) || tx_pop)입니다. Push와 Pop이 동시에 발생하면 카운트는 그대로 유지됩니다. uart_tx의 송신 레지스터는 FIFO와 별도로 한 바이트를 보유할 수 있으므로 시스템 전체 보관 용량과 FIFO 깊이 16을 혼동하지 않습니다.

031교시 ③ · Backpressure와 검증 기준 (40~60분)

Backpressure(백프레셔, 소비자가 데이터를 늦게 받도록 하는 흐름 제어)는 RX의 rx_out_ready=0으로 만들 수 있습니다. 이때 rx_out_valid=1이면 FIFO 맨 앞의 rx_out_data가 유지되어야 합니다. ready를 다시 올려 상승 에지에서 수락하면 읽기 포인터가 다음 데이터로 이동합니다.

검증은 TX에 18바이트를 연속 수락시키고 실제 직렬 출력 uart_txd_o를 별도 uart_rx로 복조해 순서를 비교합니다. RX에는 16바이트를 직렬 입력으로 넣고 ready=0으로 대기시킨 다음 순서대로 배출합니다. 마지막으로 리셋 시 유효 상태가 지워지는지 확인합니다.

042교시 ① · 전체 테스트벤치 (60~90분)

원본 3개 RTL 파일은 변경하지 않고 reference_rtl/에 바이트 동일 사본으로 보관합니다. 아래 테스트벤치는 공개 포트의 수락·데이터·순서로 PASS/FAIL을 결정합니다.

tb/ch14/tb_uart_fifo_flow.sv · SystemVerilog · 전체 코드
`timescale 1ns/1ps
// 제14장: 실제 uart_core의 RX/TX 깊이 16 FIFO를 공개 포트로 검증.
// 내부 카운터는 교육용 관찰에만 사용하며, 정답 판정은 포트 계약 중심.
module tb_uart_fifo_flow;
    localparam integer CLK_HZ=1000000, BAUD=100000, CPB=10;
    reg clk=0, resetn=0, rxd=1;
    wire txd;
    wire [7:0] rx_out_data;
    wire rx_out_valid, tx_in_ready, fe, ov;
    reg rx_out_ready=0, tx_in_valid=0;
    reg [7:0] tx_in_data=0;
    integer accepted=0, received=0, rx_checked=0;
    reg [7:0] expected_tx[0:31];
    reg [7:0] expected_rx[0:31];
    wire [7:0] mon_data;
    wire mon_valid, mon_fe, mon_ov;
    always #5 clk=~clk;

    uart_core #(.CLK_HZ(CLK_HZ), .BAUD(BAUD)) dut (
        .clk(clk), .resetn(resetn), .uart_rxd_i(rxd), .uart_txd_o(txd),
        .rx_out_data(rx_out_data), .rx_out_valid(rx_out_valid),
        .rx_out_ready(rx_out_ready), .tx_in_data(tx_in_data),
        .tx_in_valid(tx_in_valid), .tx_in_ready(tx_in_ready),
        .rx_framing_error_o(fe), .rx_overrun_o(ov)
    );
    // 실제 직렬 TX 핀을 독립 UART RX로 복조한다.
    uart_rx #(.CLK_HZ(CLK_HZ), .BAUD(BAUD)) monitor (
        .clk(clk), .resetn(resetn), .rx_i(txd),
        .out_data_o(mon_data), .out_valid_o(mon_valid),
        .out_ready_i(1'b1), .framing_error_o(mon_fe), .overrun_o(mon_ov)
    );

    // 입력 바이트를 handshake 때만 수락한다.
    task automatic push_tx(input [7:0] data);
        integer guard;
        begin
            @(negedge clk);
            tx_in_data=data; tx_in_valid=1;
            guard=0;
            while (tx_in_ready !== 1'b1) begin
                @(negedge clk);
                guard=guard+1;
                if (guard>2000) $fatal(1,"FAIL TX_READY_TIMEOUT");
            end
            @(posedge clk);
            accepted=accepted+1;
            @(negedge clk);
            tx_in_valid=0;
        end
    endtask

    // 8N1: start(0), D0~D7, stop(1). LSB부터 전송한다.
    task automatic send_rx(input [7:0] data);
        integer i;
        begin
            @(negedge clk);
            rxd=0;
            repeat(CPB) @(negedge clk);
            for(i=0;i<8;i=i+1) begin
                rxd=data[i];
                repeat(CPB) @(negedge clk);
            end
            rxd=1;
            repeat(CPB) @(negedge clk);
        end
    endtask

    // 모니터는 TX 핀의 실제 바이트와 전송 순서를 검사한다.
    always @(posedge clk) if (resetn && mon_valid) begin
        if (received>=accepted)
            $fatal(1,"FAIL UNEXPECTED_TX");
        if (mon_data !== expected_tx[received])
            $fatal(1,"FAIL TX_ORDER idx=%0d got=%h expected=%h",
                   received,mon_data,expected_tx[received]);
        received=received+1;
    end

    initial begin
        #1000000;
        $fatal(1,"FAIL GLOBAL_TIMEOUT");
    end

    integer i,guard;
    reg [7:0] held;
    initial begin
        $dumpfile("ch14_uart_fifo.vcd");
        $dumpvars(0,tb_uart_fifo_flow);
        repeat(5) @(negedge clk);
        if (tx_in_ready !== 1'b0 || rx_out_valid !== 1'b0)
            $fatal(1,"FAIL RESET_PORTS");
        resetn=1;
        @(negedge clk);
        if (tx_in_ready !== 1'b1) $fatal(1,"FAIL EMPTY_TX_READY");

        // T1: TX FIFO + PHY에 18바이트를 전송해 full/backpressure 경험.
        // 직렬 송신 중에도 FIFO는 입력을 저장한다.
        for(i=0;i<18;i=i+1) begin
            expected_tx[i]=8'h40+i;
            push_tx(8'h40+i);
        end
        guard=0;
        while(received<18) begin
            @(negedge clk);
            guard=guard+1;
            if(guard>CPB*10*22) $fatal(1,"FAIL TX_DRAIN_TIMEOUT");
        end
        if(accepted!=18 || received!=18 || mon_fe || mon_ov)
            $fatal(1,"FAIL TX_TOTAL");
        $display("T1_TX_FIFO_PASS accepted=%0d received=%0d",accepted,received);

        // T2: RX 준비를 내린 상태로 16바이트를 보내 FIFO를 채운다.
        // 포트 rx_out_data는 backpressure 동안 바뀌면 안 된다.
        rx_out_ready=0;
        for(i=0;i<16;i=i+1) begin
            expected_rx[i]=8'h80+i;
            send_rx(8'h80+i);
        end
        repeat(5) @(negedge clk);
        if(rx_out_valid !== 1'b1 || rx_out_data !== 8'h80)
            $fatal(1,"FAIL RX_HEAD");
        held=rx_out_data;
        repeat(5) begin
            @(negedge clk);
            if(rx_out_valid !== 1'b1 || rx_out_data !== held)
                $fatal(1,"FAIL RX_HOLD");
        end
        // RX를 한 바이트씩 수락하면서 데이터와 순서를 비교.
        for(i=0;i<16;i=i+1) begin
            @(negedge clk);
            if(rx_out_valid !== 1'b1 || rx_out_data !== expected_rx[i])
                $fatal(1,"FAIL RX_ORDER idx=%0d",i);
            rx_out_ready=1;
            @(posedge clk);
            rx_checked=rx_checked+1;
            @(negedge clk);
            rx_out_ready=0;
        end
        if(rx_out_valid !== 1'b0 || fe || ov || rx_checked!=16)
            $fatal(1,"FAIL RX_DRAIN");
        $display("T2_RX_BACKPRESSURE_PASS checked=%0d",rx_checked);

        // T3: Reset 시 FIFO 유효 데이터와 ready 상태 초기화.
        @(negedge clk);
        resetn=0;
        repeat(3) @(negedge clk);
        if(rx_out_valid !== 1'b0 || tx_in_ready !== 1'b0)
            $fatal(1,"FAIL RESET_FLUSH");
        resetn=1;
        @(negedge clk);
        if(tx_in_ready !== 1'b1 || rx_out_valid !== 1'b0)
            $fatal(1,"FAIL RESET_RELEASE");
        $display("T3_RESET_PASS");
        $display("PASS CH14 tx=18 rx=16");
        $finish;
    end
endmodule

코드 풀이 — 동작 순서

push_tx()는 tx_in_ready를 기다렸다가 상승 에지에서 한 바이트를 수락합니다. monitor는 실제 txd 핀의 8N1 직렬 데이터를 복조합니다. send_rx()는 시작 비트, 하위 비트부터 8비트, 정지 비트를 전송합니다. expected_tx와 expected_rx는 기대값 배열이며, !==는 X/Z까지 구별합니다.

052교시 ② · 실행과 예상 출력 (90~105분)

Ubuntu에서 bash scripts/run_ch14.sh를 실행합니다. 스크립트는 iverilog(아이베릴로그, Verilog 시뮬레이터 컴파일러)로 원본과 TB를 컴파일하고 vvp(시뮬레이션 실행기)로 실행합니다. RTL_DIR을 지정하면 다른 위치의 동일 원본 파일도 읽기 전용으로 사용할 수 있습니다.

scripts/run_ch14.sh · Bash · 전체 코드
#!/usr/bin/env bash
# 제14장: 원본 uart_core + uart_rx + uart_tx와 TB 컴파일 및 실행.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
RTL="${RTL_DIR:-$ROOT/reference_rtl}"
if ! command -v iverilog >/dev/null 2>&1 || ! command -v vvp >/dev/null 2>&1; then
  echo "NOT_RUN: iverilog 또는 vvp 없음" >&2
  exit 2
fi
for file in uart_core.v uart_rx.v uart_tx.v; do
  if [[ ! -f "$RTL/$file" ]]; then
    echo "NOT_RUN: 원본 RTL 없음: $RTL/$file" >&2
    exit 2
  fi
done
mkdir -p "$ROOT/.build/ch14"
cd "$ROOT/.build/ch14"
iverilog -g2012 -s tb_uart_fifo_flow -o sim \
  "$RTL/uart_core.v" "$RTL/uart_rx.v" "$RTL/uart_tx.v" \
  "$ROOT/tb/ch14/tb_uart_fifo_flow.sv"
vvp sim | tee simulation.log
grep -q '^PASS CH14 tx=18 rx=16$' simulation.log
