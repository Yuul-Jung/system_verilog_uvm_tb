제13장 · UART 스트림 검증

기존 Byte Stream RTL을 BFM으로 구동하고 수락·정지·오류 범위를 확인합니다.

PART 04 · CHAPTER 131교시 60분 + 2교시 60분원본 RTL 변경 없음

00개요 · UART 스트림을 거래 단위로 검증

제13장은 제4부의 시작입니다. UART(유아트, 비동기 직렬 통신) Echo(에코, 받은 값을 되돌림) 경로를 대상으로 BFM(버스 기능 모델, 테스트 입력 구동기)을 만듭니다. 기존 uart_echo_controller는 직렬 비트 수신기가 아니라 6포트 조합형 Byte Stream(바이트 스트림, 바이트 단위 전송) 전달 회로입니다. 따라서 이 장의 프레임은 TB에서 구성한 바이트 순서이며, 시작 비트·정지 비트·패리티 오류를 DUT가 검출한다고 주장하지 않습니다.

1교시 · 60분0~20분 포트 확인 / 20~40분 거래·핸드셰이크 / 40~60분 BFM 구성
2교시 · 60분60~90분 전체 TB / 90~105분 실행·예상 출력 / 105~120분 장애 분석

011교시 ① · 원본 포트와 시간 계약 (0~20분)

원본의 입력은 rx_data_i[7:0], rx_valid_i, tx_ready_i이며 출력은 tx_data_o[7:0], tx_valid_o, rx_ready_o입니다. 원본 할당식은 각각 tx_data_o = rx_data_i, tx_valid_o = rx_valid_i, rx_ready_o = tx_ready_i입니다. 클록·리셋·FIFO가 없고, 원본 회로에 레지스터 지연도 없습니다. TB의 10ns 클록과 #1은 검증용 샘플 경계일 뿐 DUT 타이밍이 아닙니다.

입력출력계약
rx_data_itx_data_o바이트 그대로 전달
rx_valid_itx_valid_o유효 신호 그대로 전달
tx_ready_irx_ready_o수신 준비 역방향 전달

021교시 ② · BFM과 수락 시점 (20~40분)

BFM은 입력을 생성하고 출력 조건을 관찰하는 TB 측 절차입니다. valid=1이고 ready=1인 샘플 에지에서 한 바이트가 수락되었다고 정의합니다. ready=0이면 data와 valid를 유지해야 같은 거래를 잃지 않습니다. DUT 자체에는 클록이 없으므로 이 수락 정의는 테스트 환경의 동기식 스트림 계약입니다.

031교시 ③ · 프레임·오류 범위 (40~60분)

교육용 프레임은 8'h41(A), 8'h5A(Z), 8'h0A(줄바꿈)의 세 바이트입니다. 두 번째 바이트에서 2샘플, 세 번째에서 1샘플의 Backpressure(백프레셔, 수신 측 전송 지연)를 발생시킵니다. 마지막에는 tx_ready_i = 1'bx를 넣어 4상태 신호 전파를 확인합니다. 이것은 UART 물리 계층 프레이밍 오류 검출 시험이 아닙니다.

위 그림은 신호 방향을 단순화한 개념도입니다. tx_ready_i는 TB에서 DUT로 입력되고 rx_ready_o는 DUT에서 TB로 돌아옵니다.

042교시 ① · 전체 테스트벤치 (60~90분)

테스트벤치에는 원본 DUT 연결, 입력 구동 작업, 공개 출력 비교, 글로벌 타임아웃을 모두 포함합니다. 비교에는 !==를 사용해 X/Z도 구별합니다.

tb/ch13/tb_uart_stream.sv · SystemVerilog · 전체 코드
`timescale 1ns/1ps
// 제13장: 기존 조합형 UART Echo Controller의 Byte Stream BFM 검증.
// 주의: 이 DUT는 UART 직렬 비트 프레임을 해독하지 않는다.
// 이 장의 '프레임'은 TB가 구성하는 바이트 거래 시퀀스이다.
module tb_uart_stream;
    reg [7:0] rx_data_i = 8'h00;
    reg rx_valid_i = 1'b0;
    reg tx_ready_i = 1'b0;
    wire rx_ready_o, tx_valid_o;
    wire [7:0] tx_data_o;
    integer checks = 0;
    integer accepted = 0;

    uart_echo_controller dut (
        .rx_data_i(rx_data_i), .rx_valid_i(rx_valid_i),
        .rx_ready_o(rx_ready_o), .tx_data_o(tx_data_o),
        .tx_valid_o(tx_valid_o), .tx_ready_i(tx_ready_i)
    );

    // TB 가상 샘플 클록: DUT에 연결되지 않는다.
    reg tb_clk = 0;
    always #5 tb_clk = ~tb_clk;

    // 조합회로 안정화 후 모든 공개 출력의 4상태 비교.
    task automatic expect_ports(
        input [7:0] data, input valid, input ready
    );
        begin
            #1;
            if (tx_data_o !== data || tx_valid_o !== valid ||
                rx_ready_o !== ready)
                $fatal(1, "FAIL data=%h valid=%b ready=%b", 
                       tx_data_o, tx_valid_o, rx_ready_o);
            checks = checks + 1;
        end
    endtask

    // BFM: 입력 바이트를 준비하고, 준비가 돌아올 때까지 유지한다.
    // stall_cycles는 수락 이전에 ready=0으로 유지할 샘플 수.
    task automatic send_byte(
        input [7:0] data, input integer stall_cycles
    );
        integer k;
        begin
            @(negedge tb_clk);
            rx_data_i = data;
            rx_valid_i = 1'b1;
            tx_ready_i = 1'b0;
            for (k = 0; k < stall_cycles; k = k + 1) begin
                expect_ports(data, 1'b1, 1'b0);
                @(posedge tb_clk);
                if (rx_ready_o !== 1'b0)
                    $fatal(1, "FAIL stall handshake");
                @(negedge tb_clk);
            end
            tx_ready_i = 1'b1;
            expect_ports(data, 1'b1, 1'b1);
            @(posedge tb_clk);
            if (rx_valid_i && rx_ready_o)
                accepted = accepted + 1;
            else
                $fatal(1, "FAIL acceptance");
            @(negedge tb_clk);
            rx_valid_i = 1'b0;
            expect_ports(data, 1'b0, 1'b1);
        end
    endtask

    initial begin
        #2000;
        $fatal(1, "FAIL GLOBAL_TIMEOUT");
    end

    initial begin
        $dumpfile("ch13_uart_stream.vcd");
        $dumpvars(0, tb_uart_stream);
        // 비활성 상태: valid=0이면 데이터가 있어도 거래가 아니다.
        expect_ports(8'h00, 1'b0, 1'b0);
        // 문자 A, Z, 줄바꿈: 3바이트 프레임의 교육용 표현.
        send_byte(8'h41, 0);
        send_byte(8'h5A, 2);
        send_byte(8'h0A, 1);
        // UART 물리 계층의 패리티/프레이밍 오류는 이 DUT에 포트가 없다.
        // 대신 준비 신호의 비정상 X 전파를 관찰하는 음성 시험.
        @(negedge tb_clk);
        rx_valid_i = 1'b1;
        rx_data_i = 8'h45;
        tx_ready_i = 1'bx;
        expect_ports(8'h45, 1'b1, 1'bx);
        @(negedge tb_clk);
        rx_valid_i = 1'b0;
        tx_ready_i = 1'b0;
        expect_ports(8'h45, 1'b0, 1'b0);
        if (accepted != 3 || checks != 12)
            $fatal(1, "FAIL count accepted=%0d checks=%0d", accepted, checks);
        $display("PASS CH13 accepted=%0d checks=%0d", accepted, checks);
        $finish;
    end
endmodule

핵심 코드 풀이

send_byte()는 전송 중단 상태를 유지한 다음 준비 신호를 올려 한 번 수락시킵니다. expect_ports()는 세 공개 출력을 비교하며 실패하면 $fatal로 종료합니다. accepted는 실제 TB 샘플 에지에서 유효·준비 조건을 만족한 횟수입니다. checks는 조합 출력 검사 횟수입니다.

052교시 ② · 실행과 예상 출력 (90~105분)

Ubuntu에서 다음 스크립트를 실행합니다. 첫 단계는 iverilog로 RTL과 TB를 컴파일하고, 다음 단계는 vvp로 실행합니다. 원본 파일은 읽기 전용 입력이며 로그와 파형은 .build/ch13/에 저장됩니다.

scripts/run_ch13.sh · Bash · 전체 코드
#!/usr/bin/env bash
# 사용: bash scripts/run_ch13.sh
# Icarus Verilog로 원본 DUT를 읽기 전용 컴파일하고 결과는 .build/ch13에 저장.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
DUT="${DUT_PATH:-$ROOT/reference_rtl/uart_echo_controller.v}"
TB="$ROOT/tb/ch13/tb_uart_stream.sv"
if [[ ! -f "$DUT" ]]; then echo "NOT_RUN: DUT 없음: $DUT" >&2; exit 2; fi
if ! command -v iverilog >/dev/null 2>&1 || ! command -v vvp >/dev/null 2>&1; then
  echo "NOT_RUN: iverilog/vvp 미설치" >&2; exit 2
fi
mkdir -p "$ROOT/.build/ch13"
cd "$ROOT/.build/ch13"
iverilog -g2012 -s tb_uart_stream -o sim "$DUT" "$TB"
vvp sim | tee simulation.log
grep -q '^PASS CH13 accepted=3 checks=12$' simulation.log

예상 출력 — 실제 실행 결과가 아님

시뮬레이션 마지막 줄 · 예상 출력 · text · 전체 코드
PASS CH13 accepted=3 checks=12

작성 환경의 RTL 시뮬레이션은 NOT_RUN입니다. 위 문자열은 예상 결과일 뿐 실제 통과 로그가 아닙니다.
