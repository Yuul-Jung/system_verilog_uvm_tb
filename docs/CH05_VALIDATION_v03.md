## 변경 사항
- 원본 전체 RTL을 TB 앞에 배치. 실제 설계 장·절, 독립 실습 경로, XSIM 실행 명령, Icarus 대체 실행 명령 제공. 교시/시간 배분 제거.
- 4개 구조체 인자에서 위치 지정 대입 패턴 `'{...}`을 동일 폭의 packed 비트 연결 `{...}`으로 변경. 모든 필드는 4상태 logic, 폭은 8+1+1=10비트. Icarus의 대입 패턴 지원 차이를 피하기 위한 호환성 대체 표현이며 컴파일 성공을 실측한 것은 아님. 기능 변경 의도 없음.
- VCD 조건부 매크로 및 실행 스크립트 -DVCD 적용. 실제 TB 56854a21a1b94da2e379204dc3dfdd5c1e2e7f0c, 스크립트 0a50714325e0d1a9eb2b8b21bba28642c76ace40.
- CASE_STALL은 독립 조합 입력 사례이며 이후 CASE_XDATA로 자극을 바꾸므로 지속적인 Ready/Valid 프로토콜이나 수락 에지 검증이 아님을 명시.
- enum은 TB 사례 이름이지 DUT FSM이 아님. X를 의도적으로 일치시키는 사례이며 정상 데이터 X를 허용하는 의미가 아님.
