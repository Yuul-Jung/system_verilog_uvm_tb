00개요 · UVM 환경의 출발점

UVM(Universal Verification Methodology, 범용 검증 방법론)은 검증 객체를 계층적으로 구성하고 공통 실행 단계를 제공합니다. 제17장은 기존 pwm_core를 변경하지 않고 uvm_test와 uvm_env를 연결하는 가장 작은 구조를 구현합니다. 이후 제18장의 Sequence·Driver, 제19장의 Monitor·Scoreboard를 얹을 수 있는 기초입니다.

1교시 60분0~20분 DUT 계약 / 20~40분 UVM 계층 / 40~60분 Phase·Objection
2교시 60분60~90분 전체 TB / 90~105분 실행 / 105~120분 오류 분석

011교시 ① · 기존 PWM의 시간 계약 (0~20분)

pwm_core는 10ns 클록의 상승 에지에서 설정을 저장합니다. resetn=0은 동기 레지스터 초기화를 유도하고 pwm_out을 조합적으로 LOW로 차단합니다. cfg_apply=1이면 설정이 Shadow에 저장되고 pending=1이 됩니다. 실제 active_period/active_duty/active_enable/active_polarity는 다음 주기 경계에서 바뀝니다. 경계와 cfg_apply가 겹치면 새 요청은 다음 경계에 반영됩니다.

실습 설정은 RESET_PERIOD=8, cfg_period=8, cfg_duty=4, cfg_enable=1, cfg_polarity=0입니다. 정상 동작에서는 한 주기 8클록 중 4클록 HIGH, 4클록 LOW를 기대합니다.

021교시 ② · uvm_test와 uvm_env (20~40분)

요소역할
pwm_test extends uvm_test환경 생성 및 시뮬레이션 종료 시점 관리
pwm_env extends uvm_env가상 인터페이스 확보, DUT 자극·검사
uvm_config_dbpwm_if 핸들을 계층에 전달
type_id::createFactory(팩토리, 등록형 객체 생성기)를 통해 환경 생성
run_testUVM 실행과 Phase 관리 시작

이 장에서는 복잡한 Agent와 Sequencer를 만들지 않습니다. UVM 구조가 실제 PWM의 리셋·설정·출력 검사와 연결되는지 확인하는 것이 목표입니다.

031교시 ③ · Phase와 Objection (40~60분)

build_phase는 구성 요소와 가상 인터페이스를 준비하는 함수 단계입니다. run_phase는 시간을 소비하는 태스크 단계로, 클록을 기다리며 DUT를 검사합니다. check_phase는 검증 횟수를 확인하고 report_phase는 결과를 기록합니다.

raise_objection()은 테스트가 아직 끝나지 않았음을 UVM에 알리고, drop_objection()은 종료할 수 있음을 알립니다. Test와 Environment의 run_phase는 병렬로 실행되므로, 이 예제는 wait(env.checks == 1)로 검사 완료를 확인한 뒤 Objection을 내립니다. Objection을 너무 일찍 내리면 검사가 중간에 종료될 수 있습니다.

042교시 ① · 전체 UVM 테스트벤치 (60~90분)

원본 reference_rtl/pwm_core.v는 수정하지 않습니다. 인터페이스·환경·테스트·Top을 하나의 파일에 넣어 계층 관계를 먼저 확인합니다. pwm_if는 TB에서 만든 연결 객체이며 원본 DUT의 포트명은 그대로 유지합니다.

tb/ch17/tb_pwm_uvm.sv · SystemVerilog / UVM · 전체 코드
`timescale 1ns/1ps
// 제17장: 기존 pwm_core를 읽기 전용 DUT로 사용하는 최소 UVM 환경.
// UVM의 build/connect/run/check/report phase와 objection 수명주기를 확인한다.
interface pwm_if(input logic clk);
    logic resetn = 0;
    logic cfg_apply = 0;
    logic [31:0] cfg_period = 8;
    logic [31:0] cfg_duty = 0;
    logic cfg_enable = 0;
    logic cfg_polarity = 0;
    wire pwm_out;
    wire pending;
    wire [31:0] active_period, active_duty;
    wire active_enable, active_polarity;
endinterface

package ch17_uvm_pkg;
    import uvm_pkg::*;
    `include "uvm_macros.svh"

    class pwm_env extends uvm_env;
        `uvm_component_utils(pwm_env)
        virtual pwm_if vif;
        int unsigned checks = 0;

        function new(string name, uvm_component parent);
            super.new(name, parent);
        endfunction

        function void build_phase(uvm_phase phase);
            super.build_phase(phase);
            if (!uvm_config_db#(virtual pwm_if)::get(this, "", "vif", vif))
                `uvm_fatal("NOVIF", "pwm_if was not provided")
        endfunction

        // 출력이 바뀌는 에지 직후를 피하고 negedge에서 확인한다.
        task automatic expect_ports(
            input logic [31:0] duty, input logic enable,
            input logic expected_pwm
        );
            @(negedge vif.clk);
            if (vif.active_period !== 32'd8 ||
                vif.active_duty !== duty ||
                vif.active_enable !== enable ||
                vif.active_polarity !== 1'b0 ||
                vif.pwm_out !== expected_pwm)
                `uvm_fatal("MISMATCH", $sformatf(
                    "period=%0d duty=%0d enable=%b pwm=%b",
                    vif.active_period, vif.active_duty,
                    vif.active_enable, vif.pwm_out))
            checks++;
        endtask

        task run_phase(uvm_phase phase);
            // DUT는 동기 리셋: resetn=0인 동안 posedge가 필요하다.
            repeat (3) @(negedge vif.clk);
            if (vif.active_period !== 32'd8 ||
                vif.active_duty !== 0 ||
                vif.active_enable !== 0 || vif.pending !== 0)
                `uvm_fatal("RESET", "PWM reset contract violated")
            `uvm_info("PWM", "RESET_CHECKED", UVM_LOW)

            // 설정은 Shadow에 저장되고, 다음 주기 경계에서 활성화된다.
            vif.resetn = 1;
            @(negedge vif.clk);
            vif.cfg_period = 8;
            vif.cfg_duty = 4;
            vif.cfg_enable = 1;
            vif.cfg_polarity = 0;
            vif.cfg_apply = 1;
            @(negedge vif.clk);
            vif.cfg_apply = 0;
            if (vif.pending !== 1'b1)
                `uvm_fatal("PENDING", "cfg_apply was not latched")

            // 8클록 주기 경계가 도래할 때까지 기다린다.
            // 비활성 상태에서 활성 상태로 전환되는 조건만 감시한다.
            begin
                int guard;
                guard = 0;
                while (vif.pending !== 1'b0) begin
                    @(negedge vif.clk);
                    guard++;
                    if (guard > 12)
                        `uvm_fatal("TIMEOUT", "PWM apply boundary timeout")
                end
            end
            if (vif.active_duty !== 32'd4 || vif.active_enable !== 1'b1)
                `uvm_fatal("APPLY", "PWM active settings mismatch")

            // duty=4, period=8: 첫 네 클록 HIGH, 다음 네 클록 LOW.
            // 경계 직후 counter=0이므로 현재 출력은 HIGH이다.
            if (vif.pwm_out !== 1'b1)
                `uvm_fatal("PWM", "Expected HIGH at new period")
            // 4번의 상승 에지 후 counter=4, 출력은 LOW.
            repeat (4) @(negedge vif.clk);
            if (vif.pwm_out !== 1'b0)
                `uvm_fatal("PWM", "Expected LOW after duty window")
            checks++;
            `uvm_info("PWM", "PWM_DUTY_CHECKED", UVM_LOW)
        endtask

        function void check_phase(uvm_phase phase);
            super.check_phase(phase);
            if (checks != 1)
                `uvm_fatal("CHECK", $sformatf("checks=%0d", checks))
        endfunction

        function void report_phase(uvm_phase phase);
            super.report_phase(phase);
            `uvm_info("RESULT", $sformatf(
                "PASS CH17 checks=%0d", checks), UVM_NONE)
        endfunction
    endclass

    class pwm_test extends uvm_test;
        `uvm_component_utils(pwm_test)
        pwm_env env;

        function new(string name, uvm_component parent);
            super.new(name, parent);
        endfunction

        function void build_phase(uvm_phase phase);
            super.build_phase(phase);
            env = pwm_env::type_id::create("env", this);
        endfunction

        task run_phase(uvm_phase phase);
            phase.raise_objection(this);
            // env의 run_phase와 test의 run_phase는 병렬 수행된다.
            // 이 장에서는 env의 완료를 기다리는 명시적 동기화가 필요하다.
            wait (env.checks == 1);
            phase.drop_objection(this);
        endtask
    endclass
endpackage

module tb_pwm_uvm;
    import uvm_pkg::*;
    import ch17_uvm_pkg::*;

    logic clk = 0;
    always #5 clk = ~clk;
    pwm_if bus(clk);

    pwm_core #(.RESET_PERIOD(8)) dut (
        .clk(clk), .resetn(bus.resetn), .cfg_apply(bus.cfg_apply),
        .cfg_period(bus.cfg_period), .cfg_duty(bus.cfg_duty),
        .cfg_enable(bus.cfg_enable), .cfg_polarity(bus.cfg_polarity),
        .pwm_out(bus.pwm_out), .pending(bus.pending),
        .active_period(bus.active_period), .active_duty(bus.active_duty),
        .active_enable(bus.active_enable),
        .active_polarity(bus.active_polarity)
    );

    initial begin
        uvm_config_db#(virtual pwm_if)::set(null, "*", "vif", bus);
        run_test("pwm_test");
    end
    initial begin
        #2000;
        $fatal(1, "FAIL CH17 GLOBAL_TIMEOUT");
    end
endmodule

코드 풀이 — 핵심 구문

`uvm_component_utils는 클래스를 Factory에 등록합니다. uvm_config_db::get 실패는 즉시 uvm_fatal로 처리하여 잘못된 연결을 숨기지 않습니다. cfg_apply를 한 클록만 유지한 뒤 pending이 내려갈 때까지 기다리므로 PWM의 Shadow→Active 전환을 실제 시간 계약에 맞춰 검사합니다. 이후 4클록 뒤 LOW가 되는지 비교합니다. !==는 X/Z 상태까지 검출합니다.

052교시 ② · 실행 및 예상 출력 (90~105분)

Ubuntu에서 먼저 UVM 라이브러리가 포함된 시뮬레이터 환경을 준비해야 합니다. UVM_HOME은 src/uvm_pkg.sv가 있는 UVM 설치 디렉터리입니다. bash scripts/run_ch17.sh는 Verilator와 UVM 파일의 존재를 확인하고 컴파일·실행한 뒤 결과 문구를 검사합니다. UVM 지원은 Verilator의 버전과 설치된 UVM 구현에 따라 달라질 수 있습니다.

scripts/run_ch17.sh · Bash · 전체 코드
#!/usr/bin/env bash
# 제17장: UVM 라이브러리가 설치된 Verilator 5.x에서 실행.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
RTL="${DUT_PATH:-$ROOT/reference_rtl/pwm_core.v}"
if [[ ! -f "$RTL" ]]; then
  echo "NOT_RUN: DUT missing: $RTL" >&2
  exit 2
fi
if ! command -v verilator >/dev/null 2>&1; then
  echo "NOT_RUN: Verilator not installed" >&2
  exit 2
fi
if [[ -z "${UVM_HOME:-}" || ! -f "$UVM_HOME/src/uvm_pkg.sv" ]]; then
  echo "NOT_RUN: UVM_HOME/src/uvm_pkg.sv not found" >&2
  exit 2
fi
mkdir -p "$ROOT/.build/ch17"
verilator --binary --timing --assert -Wno-fatal \
  --top-module tb_pwm_uvm \
  --Mdir "$ROOT/.build/ch17/obj_dir" \
  +incdir+"$UVM_HOME/src" \
  "$UVM_HOME/src/uvm_pkg.sv" "$RTL" \
  "$ROOT/tb/ch17/tb_pwm_uvm.sv"
"$ROOT/.build/ch17/obj_dir/Vtb_pwm_uvm" \
  +UVM_TESTNAME=pwm_test | tee "$ROOT/.build/ch17/simulation.log"
grep -q 'PASS CH17 checks=1' "$ROOT/.build/ch17/simulation.log"
