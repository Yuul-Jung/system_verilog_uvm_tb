제22장 · 다중 Agent·VIP

AXI4-Lite 버스와 Reset·IRQ를 별도 Agent로 구성해 Virtual Sequence로 통합 검증합니다.

PART 06 · CHAPTER 221교시 60분 + 2교시 60분기존 RTL 변경 없음

00개요 · 다중 Agent 검증 환경으로 확장

제21장에서는 RAL(알에이엘, 레지스터 추상화 계층)·Adapter(어댑터, 레지스터 거래를 버스 거래로 변환)·Predictor(프리딕터, 예측값 갱신)로 AXI4-Lite 레지스터를 검증했습니다. 이번 장은 버스 신호와 외부 하드웨어 이벤트를 각각 독립된 Agent(에이전트, 재사용 검증 구성요소 묶음)로 분리합니다.

VIP(브이아이피, 검증 지식재산)는 프로토콜 검증에 재사용하는 환경을 의미합니다. 아래 AXI VIP-style은 교육용으로 직접 작성한 Master Driver·Monitor·Sequencer이며, **AMD가 제공하는 상용 AXI VIP를 사용하거나 포함한 것은 아닙니다.**

구간시간실습 내용
1교시0~60분AXI/IRQ 두 Agent, Virtual Sequencer·Sequence, 실제 Register Map과 독립 Monitor
2교시60~120분전체 UVM 소스, 실행 스크립트, 다중 Agent 관찰·스코어보드 검증

011교시 ① · AXI와 Reset/IRQ를 분리하는 이유 (0~20분)

AXI4-Lite(에이엑스아이 포 라이트, 경량 메모리 매핑 버스)는 AW(쓰기 주소), W(쓰기 데이터), B(쓰기 응답), AR(읽기 주소), R(읽기 데이터)라는 5개의 독립 채널을 사용합니다. 반면 인터럽트와 리셋은 AXI 거래가 아닙니다. 서로 다른 시간·프로토콜 규칙을 하나의 Driver에 섞지 않는 것이 핵심입니다.

Agent실제 모듈/클래스책임
버스 Agentaxi22_bus_agentAXI Master 거래 구동, 실제 AXI Handshake(핸드셰이크, 전송 수락)를 독립 Monitor가 관찰
이벤트 Agentirq22_event_agentresetn, done_event, error_event 구동·상태 관찰
공통 시퀀서axi22_virtual_sequencerbus_sqr와 evt_sqr를 참조해 두 Agent 조정
비교기axi22_scoreboard버스 거래와 인터럽트 이벤트를 별도 Analysis(애널리시스, 관찰 이벤트 전달) 경로로 수집

구동 Driver가 발행하는 완료 메시지가 아니라, axi22_monitor가 AWVALID && AWREADY처럼 실제 신호의 전송을 관찰해 기록합니다. 따라서 제21장의 Driver 완료 기반 예측과 관찰 신뢰도가 다른 구조입니다.

021교시 ② · 실제 DUT의 주소와 입력 포트 확인 (20~40분)

기존 원본 axi4lite_slave_adapter.v와 custom_register_bank.v를 그대로 연결합니다. 비트 폭·포트 이름은 두 원본 파일을 기준으로 하며, 이번 장에서는 irq_done_event_i와 irq_error_event_i에 실제 테스트 이벤트를 공급합니다.

주소레지스터검증 동작
0x00CONTROL0x00000005 쓰기·읽기, 리셋 후 0
0x0CIRQ_STATUSdone → 1, error → 3, W1C 1 → 2, W1C 2 → 0
0x10DATA_IN0x11223344 쓰기·읽기, 리셋 후 0
0x18VERSION읽기 전용 0x00010000
0x1CID읽기 전용 0x524D4150

W1C(더블유 원 씨, Write One to Clear: 1을 써서 비트 해제)는 하드웨어 IRQ 상태만 지우는 쓰기 규칙입니다. 실제 외부 이벤트는 한 클록 펄스로 입력됩니다. 임의의 비트 패턴이 아닌, 원본 Register Bank에 정의된 주소·비트만 사용합니다.

031교시 ③ · Virtual Sequence가 두 Agent를 조정 (40~50분)

Virtual Sequence(버추얼 시퀀스, 여러 하위 시퀀스를 함께 제어하는 상위 시퀀스)는 직접 DUT 핀을 구동하지 않습니다. axi22_system_sequence가 p_sequencer.bus_sqr와 p_sequencer.evt_sqr 중 어떤 경로로 거래를 보낼지만 결정합니다.

virtual sequence의 연결 · SystemVerilog · 실제 소스 발췌
// env.connect_phase(): 하위 Sequencer 핸들을 등록
vsqr.bus_sqr=bus_agent.sqr;
vsqr.evt_sqr=event_agent.sqr;

// virtual sequence 내부의 두 종류 호출
ev(EV_DONE);          // Event Agent가 하드웨어 done 펄스 생성
rd('h0c,32'h00000001); // AXI Agent가 IRQ_STATUS 읽기

ev(EV_ERROR);
rd('h0c,32'h00000003);

제22장은 버스 요청과 하드웨어 이벤트를 순차로 조정하는 실습입니다. 동시에 여러 AXI Master를 실행하거나 이벤트를 겹치게 하는 스트레스 시험까지 포함하지는 않습니다. 두 Agent가 서로 다른 구동·관찰 경로를 갖는 것이 핵심입니다.

041교시 ④ · 독립 Monitor와 통합 Scoreboard (50~60분)

AXI Monitor는 실제 AW/W 수락을 별도로 저장하고 B 응답을 수락할 때 하나의 완료 쓰기 거래를 전달합니다. 읽기는 AR 주소를 저장하고 R 응답 수락에서 거래를 보냅니다. 반면 Event Monitor는 리셋 하강과 IRQ 펄스를 상승 에지 이후에 읽습니다.

Scoreboard(스코어보드)는 expected_control, expected_data, expected_irq를 보관합니다. 이는 DUT 내부 레지스터를 그대로 읽어 생성한 값이 아니라, 시나리오의 쓰기·이벤트 규칙을 바탕으로 갱신하는 독립 기대값입니다. 완료 쓰기가 관찰된 다음 IRQ 읽기를 수행하기 때문에 W1C 판정과 실제 AXI 응답 순서를 비교할 수 있습니다.

`timescale 1ns/1ps
// 제22장: AXI4-Lite Master Agent + Reset/IRQ Agent + Virtual Sequence.
// 상용 AMD AXI VIP가 아닌 교육용 VIP-style(재사용 검증 컴포넌트) 구현.
// 기존 axi4lite_slave_adapter.v 및 custom_register_bank.v는 수정하지 않는다.

// (추가) 버스 전용 Interface: AXI 신호만 묶는다.
interface axi22_if(input logic clk, input logic resetn);
    logic [31:0] awaddr=0, wdata=0, araddr=0;
    logic [3:0] wstrb=0;
    logic awvalid=0, wvalid=0, bready=0, arvalid=0, rready=0;
    wire awready, wready, bvalid, arready, rvalid;
    wire [1:0] bresp, rresp;
    wire [31:0] rdata;
endinterface

// (추가) 하드웨어 이벤트 전용 Interface: AXI와 구동 책임을 분리한다.
interface irq22_if(input logic clk);
    logic resetn=0;
    logic done_event=0, error_event=0;
    wire [1:0] irq_status;
endinterface

package ch22_pkg;
    import uvm_pkg::*;
    `include "uvm_macros.svh"

    // 두 개의 독립 Analysis Imp(write_bus/write_irq)를 선언한다.
    `uvm_analysis_imp_decl(_bus)
    `uvm_analysis_imp_decl(_irq)

    // AXI Master Driver: AW/W 독립 Handshake와 B/R Backpressure를 보존한다.
    class axi22_driver extends uvm_driver #(axi22_item);
        `uvm_component_utils(axi22_driver)
        virtual axi22_if vif;
        int unsigned driven=0;
        function new(string name,uvm_component parent);
            super.new(name,parent);
        endfunction
        function void build_phase(uvm_phase phase);
            super.build_phase(phase);
            if (!uvm_config_db#(virtual axi22_if)::get(this,"","vif",vif))
                `uvm_fatal("AXI_VIF","AXI interface missing")
        endfunction
        task automatic write_one(axi22_item t);
            bit aw_done=0, w_done=0;
            @(negedge vif.clk);
            vif.awaddr=t.addr; vif.awvalid=1'b1;
            vif.wdata=t.data; vif.wstrb=t.strb; vif.wvalid=1'b1;
            for (int k=0;k<100;k++) begin
                @(posedge vif.clk);
                if (vif.awvalid && vif.awready) aw_done=1;
                if (vif.wvalid && vif.wready) w_done=1;
                @(negedge vif.clk);
                if (aw_done) vif.awvalid=1'b0;
                if (w_done) vif.wvalid=1'b0;
                if (aw_done && w_done) break;
            end
            if (!aw_done || !w_done)
                `uvm_fatal("AXI_AW_W","Write handshake timeout")
            for (int k=0;k<100;k++) begin
                @(negedge vif.clk);
                if (vif.bvalid) begin
                    t.resp=vif.bresp;
                    // 두 클록 동안 BREADY=0 → 응답 유지 후 수락.
                    repeat (2) @(negedge vif.clk);
                    if (vif.bvalid !== 1'b1)
                        `uvm_fatal("B_HOLD","BVALID dropped during stall")
                    vif.bready=1'b1;
                    @(posedge vif.clk);
                    @(negedge vif.clk);
                    vif.bready=1'b0;
                    return;
                end
            end
            `uvm_fatal("B_TIMEOUT","Write response timeout")
        endtask
        task automatic read_one(axi22_item t);
            bit ar_done=0;
            @(negedge vif.clk);
            vif.araddr=t.addr; vif.arvalid=1'b1;
            for (int k=0;k<100;k++) begin
                @(posedge vif.clk);
                if (vif.arvalid && vif.arready) ar_done=1;
                @(negedge vif.clk);
                if (ar_done) begin vif.arvalid=1'b0; break; end
            end
            if (!ar_done) `uvm_fatal("AR_TIMEOUT","Read address timeout")
            for (int k=0;k<100;k++) begin
                @(negedge vif.clk);
                if (vif.rvalid) begin
                    t.data=vif.rdata; t.resp=vif.rresp;
                    // 두 클록 동안 RREADY=0 → 데이터 유지 검사.
                    repeat (2) @(negedge vif.clk);
                    if (vif.rvalid !== 1'b1 || vif.rdata !== t.data)
                        `uvm_fatal("R_HOLD","Read response changed during stall")
                    vif.rready=1'b1;
                    @(posedge vif.clk);
                    @(negedge vif.clk);
                    vif.rready=1'b0;
                    return;
                end
            end
            `uvm_fatal("R_TIMEOUT","Read response timeout")
        endtask
        task run_phase(uvm_phase phase);
            axi22_item req;
            forever begin
                seq_item_port.get_next_item(req);
                if (req.is_write) write_one(req);
                else read_one(req);
                driven++;
                seq_item_port.item_done();
            end
        endtask
    endclass

    // AXI Monitor는 Driver 완료 이벤트를 쓰지 않고 실제 5채널을 관찰한다.
    class axi22_monitor extends uvm_monitor;
        `uvm_component_utils(axi22_monitor)
        virtual axi22_if vif;
        uvm_analysis_port #(axi22_item) ap;
        bit aw_seen=0, w_seen=0, ar_seen=0;
        bit [31:0] saved_aw, saved_wd, saved_ar;
        bit [3:0] saved_strb;
        function new(string name,uvm_component parent);
            super.new(name,parent);
            ap=new("ap",this);
        endfunction
        function void build_phase(uvm_phase phase);
            super.build_phase(phase);
            if (!uvm_config_db#(virtual axi22_if)::get(this,"","vif",vif))
                `uvm_fatal("AXI_VIF","AXI monitor interface missing")
        endfunction
        task run_phase(uvm_phase phase);
            axi22_item s;
            forever begin
                @(posedge vif.clk); // DUT가 Handshake를 읽는 에지에서 관찰
                if (!vif.resetn) begin
                    aw_seen=0; w_seen=0; ar_seen=0;
                end else begin
                    if (vif.awvalid && vif.awready) begin
                        saved_aw=vif.awaddr; aw_seen=1;
                    end
                    if (vif.wvalid && vif.wready) begin
                        saved_wd=vif.wdata; saved_strb=vif.wstrb; w_seen=1;
                    end
                    if (vif.arvalid && vif.arready) begin
                        saved_ar=vif.araddr; ar_seen=1;
                    end
                    if (vif.bvalid && vif.bready) begin
                        if (!aw_seen || !w_seen)
                            `uvm_fatal("AXI_MON_B","B before AW/W Handshake")
                        s=axi22_item::type_id::create("observed_write");
                        s.is_write=1; s.addr=saved_aw; s.data=saved_wd;
                        s.strb=saved_strb; s.resp=vif.bresp;
                        ap.write(s);
                        aw_seen=0; w_seen=0;
                    end
                    if (vif.rvalid && vif.rready) begin
                        if (!ar_seen)
                            `uvm_fatal("AXI_MON_R","R before AR Handshake")
                        s=axi22_item::type_id::create("observed_read");
                        s.is_write=0; s.addr=saved_ar; s.data=vif.rdata;
                        s.resp=vif.rresp;
                        ap.write(s);
                        ar_seen=0;
                    end
                end
            end
        endtask
    endclass

    // 별도 Event Driver는 Reset/IRQ 입력만 구동한다.
    class irq22_driver extends uvm_driver #(irq22_item);
        `uvm_component_utils(irq22_driver)
        virtual irq22_if vif;
        int unsigned events_driven=0;
        function new(string name,uvm_component parent);
            super.new(name,parent);
        endfunction
        function void build_phase(uvm_phase phase);
            super.build_phase(phase);
            if (!uvm_config_db#(virtual irq22_if)::get(this,"","vif",vif))
                `uvm_fatal("IRQ_VIF","IRQ interface missing")
        endfunction
        task run_phase(uvm_phase phase);
            irq22_item req;
            forever begin
                seq_item_port.get_next_item(req);
                case (req.kind)
                    EV_RELEASE: begin
                        @(negedge vif.clk);
                        vif.resetn=1'b1;
                    end
                    EV_ASSERT_RESET: begin
                        @(negedge vif.clk);
                        vif.resetn=1'b0;
                        repeat (3) @(negedge vif.clk);
                    end
                    EV_DONE: begin
                        @(negedge vif.clk);
                        vif.done_event=1'b1;
                        @(negedge vif.clk);
                        vif.done_event=1'b0;
                    end
                    EV_ERROR: begin
                        @(negedge vif.clk);
                        vif.error_event=1'b1;
                        @(negedge vif.clk);
                        vif.error_event=1'b0;
                    end
                endcase
                events_driven++;
                seq_item_port.item_done();
            end
        endtask
    endclass

    // 별도 Event Monitor: IRQ 상태·Reset을 관찰해 Scoreboard에 전달.
    class irq22_monitor extends uvm_monitor;
        `uvm_component_utils(irq22_monitor)
        virtual irq22_if vif;
        uvm_analysis_port #(irq22_sample) ap;
        bit previous_resetn=1'b1;
        function new(string name,uvm_component parent);
            super.new(name,parent);
            ap=new("ap",this);
        endfunction
        function void build_phase(uvm_phase phase);
            super.build_phase(phase);
            if (!uvm_config_db#(virtual irq22_if)::get(this,"","vif",vif))
                `uvm_fatal("IRQ_VIF","IRQ monitor interface missing")
        endfunction
        task run_phase(uvm_phase phase);
            irq22_sample s;
            forever begin
                @(posedge vif.clk);
                #1; // 레지스터 뱅크 NBA 갱신이 완료된 시점
                if (!vif.resetn && previous_resetn) begin
                    s=irq22_sample::type_id::create("reset_event");
                    s.kind=EV_ASSERT_RESET; s.status=vif.irq_status;
                    s.stamp=$time; ap.write(s);
                end
                previous_resetn=(vif.resetn===1'b1);
                if (vif.resetn && vif.done_event) begin
                    s=irq22_sample::type_id::create("done_event");
                    s.kind=EV_DONE; s.status=vif.irq_status;
                    s.stamp=$time; ap.write(s);
                end
                if (vif.resetn && vif.error_event) begin
                    s=irq22_sample::type_id::create("error_event");
                    s.kind=EV_ERROR; s.status=vif.irq_status;
                    s.stamp=$time; ap.write(s);
                end
            end
        endtask
    endclass

    // 버스 완료 관찰과 IRQ 이벤트 관찰을 별도 Analysis Imp로 수집.
    class axi22_scoreboard extends uvm_scoreboard;
        `uvm_component_utils(axi22_scoreboard)
        uvm_analysis_imp_bus #(axi22_item,axi22_scoreboard) bus_in;
        uvm_analysis_imp_irq #(irq22_sample,axi22_scoreboard) irq_in;
        bit [31:0] expected_control=0, expected_data=0;
        bit [1:0] expected_irq=0;
        int unsigned writes=0, reads=0, events=0, resets=0;
        function new(string name,uvm_component parent);
            super.new(name,parent);
            bus_in=new("bus_in",this);
            irq_in=new("irq_in",this);
        endfunction

        function void write_bus(axi22_item s);
            bit [31:0] exp_data;
            if (s.resp !== 2'b00)
                `uvm_fatal("AXI_RESP","Non-OKAY AXI response")
            if (s.is_write) begin
                case (s.addr)
                    'h00: if (s.strb[0])
                        expected_control={29'd0,s.data[2:0]};
                    'h10: for (int i=0;i<4;i++)
                        if (s.strb[i])
                            expected_data[i*8 +: 8]=s.data[i*8 +: 8];
                    'h0c: if (s.strb[0])
                        expected_irq=expected_irq & ~s.data[1:0];
                    default: `uvm_fatal("AXI_WR_ADDR","Unexpected write address")
                endcase
                writes++;
            end else begin
                case (s.addr)
                    'h00: exp_data=expected_control;
                    'h0c: exp_data={30'd0,expected_irq};
                    'h10: exp_data=expected_data;
                    'h18: exp_data=32'h00010000;
                    'h1c: exp_data=32'h524D4150;
                    default: `uvm_fatal("AXI_RD_ADDR","Unexpected read address")
                endcase
                if (s.data !== exp_data)
                    `uvm_fatal("AXI_READ_MISMATCH",
                        $sformatf("addr=%h got=%h expected=%h",
                                  s.addr,s.data,exp_data))
                reads++;
            end
        endfunction

        function void write_irq(irq22_sample s);
            case (s.kind)
                EV_ASSERT_RESET: begin
                    expected_irq=2'b00;
                    expected_control=0; expected_data=0; resets++;
                end
                EV_DONE: begin expected_irq[0]=1'b1; events++; end
                EV_ERROR: begin expected_irq[1]=1'b1; events++; end
                default: `uvm_fatal("IRQ_KIND","Unexpected IRQ monitor event")
            endcase
            if (s.status !== expected_irq)
                `uvm_fatal("IRQ_MISMATCH",
                    $sformatf("IRQ status=%b expected=%b",
                              s.status,expected_irq))
        endfunction
    endclass

            irq22_event_sequence s=irq22_event_sequence::type_id::create("ev");
            s.kind=kind;
            s.start(p_sequencer.evt_sqr);
        endtask

        task automatic wr(bit [31:0] a,bit [31:0] d,bit [3:0] strb=4'hf);
            axi22_bus_sequence s=axi22_bus_sequence::type_id::create("write");
            s.is_write=1; s.addr=a; s.send_data=d; s.strb=strb;
            s.start(p_sequencer.bus_sqr);
            if (s.return_resp !== 2'b00)
                `uvm_fatal("WRITE","Write response was not OKAY")
        endtask

        task automatic rd(bit [31:0] a,bit [31:0] expected);
            axi22_bus_sequence s=axi22_bus_sequence::type_id::create("read");
            s.is_write=0; s.addr=a;
            s.start(p_sequencer.bus_sqr);
            if (s.return_resp !== 2'b00 || s.return_data !== expected)
                `uvm_fatal("READ",
                    $sformatf("addr=%h got=%h expected=%h",
                              a,s.return_data,expected))
        endtask

        task body();
            // 초기 리셋 → 제어/데이터 레지스터 접근.
            ev(EV_RELEASE);
            wr('h00,32'h00000005);
            wr('h10,32'h11223344);
            rd('h00,32'h00000005);
            rd('h10,32'h11223344);

            // 실제 HW IRQ 이벤트 발생 → AXI Read로 관찰.
            ev(EV_DONE);
            rd('h0c,32'h00000001);
            ev(EV_ERROR);
            rd('h0c,32'h00000003);

            // W1C(Write 1 to Clear, 1을 써서 상태 비트 해제) 시험.
            wr('h0c,32'h00000001);
            rd('h0c,32'h00000002);
            wr('h0c,32'h00000002);
            rd('h0c,32'h00000000);

            // RO 레지스터와 리셋 후 상태 초기화 확인.
            rd('h18,32'h00010000);
            rd('h1c,32'h524D4150);
            ev(EV_ASSERT_RESET);
            ev(EV_RELEASE);
            rd('h0c,32'h00000000);
            rd('h00,32'h00000000);
            rd('h10,32'h00000000);
        endtask
    endclass

            repeat (2) @(negedge irq_vif.clk);

                env.bus_agent.drv.driven!=15 ||
                env.event_agent.drv.events_driven!=5)

                    $sformatf("W=%0d R=%0d IRQ=%0d RESET=%0d",
                              env.sb.writes,env.sb.reads,
                              env.sb.events,env.sb.resets))
            `uvm_info("RESULT",
                "PASS CH22 AXI_W=4 AXI_R=11 IRQ=2 RESET=2",UVM_NONE)
            phase.drop_objection(this);
        endtask

코드 풀이 — 역할과 데이터의 연결

axi22_driver.write_one()은 AW/W의 독립 수락을 확인하고 BREADY를 일부러 늦춥니다. read_one()도 RREADY를 늦춘 뒤 RDATA가 유지되는지 검사합니다. axi22_monitor는 Driver 내부의 driven이나 응답 객체를 읽지 않고 공개된 핸드셰이크만 수집합니다.

irq22_driver는 Reset, Done, Error만 구동하고 irq22_monitor는 실제 irq_status 변화를 관찰합니다. 각 Monitor의 ap.write() 결과는 각각 sb.bus_in과 sb.irq_in에 도달합니다. 버스 데이터 정답과 하드웨어 이벤트 정답을 한 곳에서 비교하되, 관찰 경로는 끝까지 분리됩니다.

062교시 ② · Ubuntu 실행 스크립트 (95~108분)

원본 RTL 2개와 신규 UVM 테스트벤치 하나를 함께 컴파일합니다. Verilator(베릴레이터, SystemVerilog 시뮬레이터)와 호환되는 UVM 라이브러리가 필요하며, 지원하지 않는 조합에서는 컴파일 오류가 발생할 수 있습니다.

scripts/run_ch22.sh · Bash · 전체 실행 스크립트 · 미실행
#!/usr/bin/env bash
# CH22: AXI4-Lite Agent + IRQ/Reset Agent + Virtual Sequence UVM 실행.
# 상용 AXI VIP가 아니라 교육용 VIP-style AXI BFM과 독립 Monitor를 사용한다.
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
RTL="${RTL_DIR:-$ROOT/reference_rtl}"
TB="$ROOT/tb/ch22/tb_axi_multiagent_irq.sv"
OUT="$ROOT/.build/ch22"

for p in "$RTL/axi4lite_slave_adapter.v" \
         "$RTL/custom_register_bank.v" "$TB"; do
  if [[ ! -f "$p" ]]; then
    echo "NOT_RUN: source file not found: $p" >&2
    exit 2
  fi
done
if ! command -v verilator >/dev/null 2>&1; then
  echo "NOT_RUN: Verilator is not installed" >&2
  exit 2
fi
if [[ -z "${UVM_HOME:-}" || ! -f "$UVM_HOME/src/uvm_pkg.sv" ]]; then
  echo "NOT_RUN: compatible UVM_HOME/src/uvm_pkg.sv is required" >&2
  exit 2
fi

mkdir -p "$OUT"
verilator --version | tee "$OUT/tool_version.txt"

# --timing: UVM 이벤트와 지연; --trace: VCD 기록; --assert: 검사.
# 실제 UVM 호환성은 설치된 Verilator/UVM 버전으로 확인해야 한다.
verilator --binary --timing --assert --trace -Wno-fatal \
  --top-module tb_axi_multiagent_irq --Mdir "$OUT/obj_dir" \
  +incdir+"$UVM_HOME/src" \
  "$UVM_HOME/src/uvm_pkg.sv" \
  "$RTL/axi4lite_slave_adapter.v" \
  "$RTL/custom_register_bank.v" "$TB" \
  2>&1 | tee "$OUT/build.log"

(cd "$OUT" && ./obj_dir/Vtb_axi_multiagent_irq \
  +UVM_TESTNAME=axi22_test | tee simulation.log)

# UVM 결과 문구와 실제 에러 수(0)를 독립적으로 확인한다.
if ! grep -q 'PASS CH22 AXI_W=4 AXI_R=11 IRQ=2 RESET=2' "$OUT/simulation.log"; then
  echo "FAIL: multi-agent scoreboard did not complete all checks" >&2
  exit 1
fi
# UVM_ERROR : 0 / UVM_FATAL : 0은 정상 요약이다.
if grep -Eq 'UVM_(ERROR|FATAL) @[[:space:]]*[0-9]+|UVM_(ERROR|FATAL)[[:space:]]*:[[:space:]]*[1-9]' "$OUT/simulation.log"; then
  echo "FAIL: UVM_ERROR or UVM_FATAL detected" >&2
  exit 1
fi
echo "PASS CH22 SUITE: 4 writes, 11 reads, 2 IRQ events, 2 resets"
echo "Logs: $OUT/build.log and $OUT/simulation.log"
echo "Waveform (if generated): $OUT/ch22_multiagent_axi_irq.vcd"

실행 스크립트는 set -euo pipefail로 컴파일 또는 시뮬레이터 실패를 전파하고, 성공 종료만으로 판정하지 않고 PASS CH22 AXI_W=4 AXI_R=11 IRQ=2 RESET=2라는 집계 문자열과 실제 UVM 오류 여부를 함께 확인하도록 구성했습니다.

092교시 ⑤ · 핵심 정리 (118~120분)

두 Agent는 서로 다른 신호 그룹을 구동·관찰합니다. Virtual Sequence는 두 Sequencer를 조정합니다. Scoreboard는 AXI 완료 거래와 IRQ 이벤트라는 독립 경로를 받아 레지스터 기대값을 검사합니다. 기존 DUT 수정 없이 검증 영역을 시스템 수준으로 확장한 것입니다.

module axi4lite_slave_adapter #(
    parameter integer C_S_AXI_ADDR_WIDTH = 32
)(
    input  wire                          s_axi_aclk,
    input  wire                          s_axi_aresetn,

    // AXI4-Lite Write Address Channel
    input  wire [C_S_AXI_ADDR_WIDTH-1:0] s_axi_awaddr,
    input  wire [2:0]                    s_axi_awprot,
    input  wire                          s_axi_awvalid,
    output wire                          s_axi_awready,

    // AXI4-Lite Write Data Channel
    input  wire [31:0]                   s_axi_wdata,
    input  wire [3:0]                    s_axi_wstrb,
    input  wire                          s_axi_wvalid,
    output wire                          s_axi_wready,

    // AXI4-Lite Write Response Channel
    output reg  [1:0]                    s_axi_bresp,
    output reg                           s_axi_bvalid,
    input  wire                          s_axi_bready,

    // AXI4-Lite Read Address Channel
    input  wire [C_S_AXI_ADDR_WIDTH-1:0] s_axi_araddr,
    input  wire [2:0]                    s_axi_arprot,
    input  wire                          s_axi_arvalid,
    output wire                          s_axi_arready,

    // AXI4-Lite Read Data Channel
    output reg  [31:0]                   s_axi_rdata,
    output reg  [1:0]                    s_axi_rresp,
    output reg                           s_axi_rvalid,
    input  wire                          s_axi_rready,

    // Bus-independent register access interface
    output wire                          wr_en,
    output wire [7:0]                    wr_offset,
    output wire [31:0]                   wr_data,
    output wire [3:0]                    wr_strb,

    output wire [7:0]                    rd_offset,
    input  wire [31:0]                   rd_data
);

// AXI response code used by this basic slave.
localparam [1:0] AXI_RESP_OKAY = 2'b00;

// Write Address and Write Data are independent AXI channels.
// Each channel is buffered separately until both are available.
reg                          aw_stored;
reg [C_S_AXI_ADDR_WIDTH-1:0] awaddr_stored;
reg                          w_stored;
reg [31:0]                   wdata_stored;
reg [3:0]                    wstrb_stored;

wire write_commit;

// Single-outstanding-write policy:
// Do not accept a new write while a response is pending.
assign s_axi_awready =
    s_axi_aresetn && !aw_stored && !s_axi_bvalid;

assign s_axi_wready =
    s_axi_aresetn && !w_stored && !s_axi_bvalid;

// Register-bank write occurs only after BOTH address and data
// channels have completed their independent handshakes.
assign write_commit =
    aw_stored && w_stored && !s_axi_bvalid;

assign wr_en     = write_commit;
assign wr_offset = awaddr_stored[7:0];
assign wr_data   = wdata_stored;
assign wr_strb   = wstrb_stored;

// Read side accepts one address only when no previous R response
// is waiting for the master.
assign s_axi_arready =
    s_axi_aresetn && !s_axi_rvalid;

// custom_register_bank read path is combinational.
// The address presented during AR handshake selects rd_data.
assign rd_offset = s_axi_araddr[7:0];

// AWPROT / ARPROT are not used by this educational register slave.
wire unused_prot;
assign unused_prot = ^{s_axi_awprot, s_axi_arprot};

always @(posedge s_axi_aclk) begin
    if (!s_axi_aresetn) begin
        aw_stored     <= 1'b0;
        awaddr_stored <= {C_S_AXI_ADDR_WIDTH{1'b0}};
        w_stored      <= 1'b0;
        wdata_stored  <= 32'h0000_0000;
        wstrb_stored  <= 4'b0000;
        s_axi_bresp   <= AXI_RESP_OKAY;
        s_axi_bvalid  <= 1'b0;
    end else begin
        // Capture Write Address independently.
        if (s_axi_awready && s_axi_awvalid) begin
            aw_stored     <= 1'b1;
            awaddr_stored <= s_axi_awaddr;
        end

        // Capture Write Data independently.
        if (s_axi_wready && s_axi_wvalid) begin
            w_stored     <= 1'b1;
            wdata_stored <= s_axi_wdata;
            wstrb_stored <= s_axi_wstrb;
        end

        // Once both parts exist, pulse wr_en through write_commit
        // and create the AXI B response.
        if (write_commit) begin
            aw_stored    <= 1'b0;
            w_stored     <= 1'b0;
            s_axi_bresp  <= AXI_RESP_OKAY;
            s_axi_bvalid <= 1'b1;
        end else if (s_axi_bvalid && s_axi_bready) begin
            s_axi_bvalid <= 1'b0;
        end
    end
end

always @(posedge s_axi_aclk) begin
    if (!s_axi_aresetn) begin
        s_axi_rdata  <= 32'h0000_0000;
        s_axi_rresp  <= AXI_RESP_OKAY;
        s_axi_rvalid <= 1'b0;
    end else begin
        // Capture the selected register value at AR handshake.
        if (s_axi_arready && s_axi_arvalid) begin
            s_axi_rdata  <= rd_data;
            s_axi_rresp  <= AXI_RESP_OKAY;
            s_axi_rvalid <= 1'b1;
        end else if (s_axi_rvalid && s_axi_rready) begin
            s_axi_rvalid <= 1'b0;
        end
    end
end

endmodule

module custom_register_bank (
    input  wire        clk,
    input  wire        resetn,

    // Bus-independent register access interface.
    // SoC 12 will connect this interface to AXI4-Lite.
    input  wire        wr_en,
    input  wire [7:0]  wr_offset,
    input  wire [31:0] wr_data,
    input  wire [3:0]  wr_strb,

    input  wire [7:0]  rd_offset,
    output reg  [31:0] rd_data,

    // Hardware status / event inputs
    input  wire        busy_i,
    input  wire        done_i,
    input  wire        error_i,
    input  wire        irq_done_event_i,
    input  wire        irq_error_event_i,
    input  wire [31:0] data_out_i,

    // Control outputs
    output reg         enable_o,
    output reg  [1:0]  mode_o,
    output reg         start_pulse_o,
    output reg         clear_pulse_o,
    output reg  [31:0] data_in_o,
    output reg  [1:0]  irq_status_o
);

localparam [7:0] REG_CONTROL    = 8'h00;
localparam [7:0] REG_STATUS     = 8'h04;
localparam [7:0] REG_COMMAND    = 8'h08;
localparam [7:0] REG_IRQ_STATUS = 8'h0C;
localparam [7:0] REG_DATA_IN    = 8'h10;
localparam [7:0] REG_DATA_OUT   = 8'h14;
localparam [7:0] REG_VERSION    = 8'h18;
localparam [7:0] REG_ID         = 8'h1C;

localparam [31:0] VERSION_VALUE = 32'h0001_0000;
localparam [31:0] ID_VALUE      = 32'h524D_4150; // ASCII "RMAP"

integer byte_index;

always @(posedge clk) begin
    if (!resetn) begin
        enable_o      <= 1'b0;
        mode_o        <= 2'b00;
        start_pulse_o <= 1'b0;
        clear_pulse_o <= 1'b0;
        data_in_o     <= 32'h0000_0000;
        irq_status_o  <= 2'b00;
    end else begin
        // W1P pulses are one clock wide by default.
        start_pulse_o <= 1'b0;
        clear_pulse_o <= 1'b0;

        // Hardware events set IRQ status.
        // Event set has priority over software clear in the same cycle.
        if (irq_done_event_i) begin
            irq_status_o[0] <= 1'b1;
        end else if (
            wr_en &&
            (wr_offset == REG_IRQ_STATUS) &&
            wr_strb[0] &&
            wr_data[0]
        ) begin
            irq_status_o[0] <= 1'b0;
        end

        if (irq_error_event_i) begin
            irq_status_o[1] <= 1'b1;
        end else if (
            wr_en &&
            (wr_offset == REG_IRQ_STATUS) &&
            wr_strb[0] &&
            wr_data[1]
        ) begin
            irq_status_o[1] <= 1'b0;
        end

        if (wr_en) begin
            case (wr_offset)
                REG_CONTROL: begin
                    if (wr_strb[0]) begin
                        enable_o <= wr_data[0];
                        mode_o   <= wr_data[2:1];
                    end
                end

                REG_COMMAND: begin
                    if (wr_strb[0]) begin
                        start_pulse_o <= wr_data[0];
                        clear_pulse_o <= wr_data[1];
                    end
                end

                REG_DATA_IN: begin
                    // Byte-enable write using WSTRB-equivalent strobes.
                    for (byte_index = 0; byte_index < 4; byte_index = byte_index + 1) begin
                        if (wr_strb[byte_index]) begin
                            data_in_o[byte_index*8 +: 8] <=
                                wr_data[byte_index*8 +: 8];
                        end
                    end
                end

                default: begin
                    // RO / reserved / unmapped writes have no effect.
                end
            endcase
        end
    end
end

always @(*) begin
    case (rd_offset)
        REG_CONTROL: begin
            rd_data = {29'h0, mode_o, enable_o};
        end

        REG_STATUS: begin
            rd_data = {29'h0, error_i, done_i, busy_i};
        end

        REG_COMMAND: begin
            // W1P command register has no retained state.
            rd_data = 32'h0000_0000;
        end

        REG_IRQ_STATUS: begin
            rd_data = {30'h0, irq_status_o};
        end

        REG_DATA_IN: begin
            rd_data = data_in_o;
        end

        REG_DATA_OUT: begin
            rd_data = data_out_i;
        end

        REG_VERSION: begin
            rd_data = VERSION_VALUE;
        end

        REG_ID: begin
            rd_data = ID_VALUE;
        end

        default: begin
            rd_data = 32'h0000_0000;
        end
    endcase
end

endmodule

특히 wr_en은 AW와 W 채널 모두 수락된 뒤 발생하며, 하드웨어 IRQ 이벤트 입력은 레지스터 뱅크의 irq_done_event_i·irq_error_event_i에 연결됩니다.
