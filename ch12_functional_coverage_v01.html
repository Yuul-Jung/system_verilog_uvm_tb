제12장 · 기능 커버리지

테스트가 통과했다는 사실과, 어떤 입력 조합을 실제로 확인했는지를 구별합니다.

PART 03 · CHAPTER 121교시 60분 + 2교시 60분DUT 원본 보존

00개요 · 검증의 빈틈을 수치로 확인하기

제11장에서는 속성 위반을 검사했습니다. 이번에는 어떤 설정을 실제로 시험했는가를 계량합니다. 기능 커버리지(Functional Coverage, 기능별 검증 범위)는 정답 판정과 다릅니다. 100% 커버리지라도 출력 오류가 있을 수 있으므로 반드시 파형 검사와 함께 사용합니다.

교시시간내용
1교시 60분0~20분 / 20~40분 / 40~60분기존 PWM 계약 → bins 분류 → cross와 샘플 시점
2교시 60분60~90분 / 90~105분 / 105~120분전체 TB → 실행·예상 출력 → 코드 풀이·장애 분석

이 도식은 TB의 검증 흐름을 간략화한 개념도입니다. cov.sample()은 파형 검사에 통과한 뒤에만 호출됩니다.

011교시 ① · 실제 PWM 포트와 시간 계약 (0~20분)

원본 pwm_core에는 7개 입력(clk, resetn, cfg_apply, cfg_period, cfg_duty, cfg_enable, cfg_polarity)과 6개 출력(pwm_out, pending, active_period, active_duty, active_enable, active_polarity)이 있습니다. 이 장에서는 RESET_PERIOD=8, cfg_period=8로 고정합니다.

cfg_apply는 상승 에지에 Shadow(섀도, 대기 설정)로 캡처되고 pending이 1이 됩니다. 활성 설정은 이후 주기 경계에서 갱신됩니다. resetn=0일 때 출력은 즉시 LOW로 차단되며 레지스터는 상승 에지에 초기화됩니다. 원본에 없는 Ready/Valid 포트나 임의의 수락 신호를 가정하지 않습니다.

정상 극성에서 duty 0/4/8은 각각 한 주기 동안 HIGH 0/4/8클록입니다. 반전 극성은 HIGH 수를 8에서 빼고, cfg_enable=0이면 극성과 무관하게 HIGH 0클록입니다.

021교시 ② · coverpoint와 bins (20~40분)

covergroup(커버그룹, 검증 항목 묶음)은 샘플 이벤트에서 값의 분포를 기록합니다. coverpoint(커버포인트, 관찰 변수)는 한 입력을 분류하며 bins(빈즈, 값의 구간)는 확인해야 할 범위입니다.

커버포인트구간의미
cp_dutyzero / middle / full0%, 중간 1~7, 100%
cp_enabledisabled / enabled출력 차단·허용
cp_polaritynormal / inverted정상·반전 극성

illegal_bins outside = default는 범위 밖의 설정을 검증 오류로 구분합니다. 단, 본 실습의 듀티 범위는 period 8을 전제로 하므로 다른 주기 설정에 그대로 적용하면 안 됩니다.

031교시 ③ · cross와 샘플 시점 (40~60분)

cross cp_duty, cp_enable, cp_polarity는 3×2×2, 총 12개의 설정 조합을 만듭니다. 단순히 각각의 입력값을 한 번씩 시험하는 것과 달리, 조합별 누락을 찾아냅니다. get_coverage()는 이 커버그룹의 종합 커버리지 비율입니다. 이 실습은 모든 항목을 전부 방문하도록 12개 조합을 순회합니다.

설정 직후 cov.sample()을 호출하면 아직 active_duty가 이전 값일 수 있습니다. 따라서 pending이 해제되고 활성 설정이 일치하는지 확인한 뒤 8클록 출력 파형을 검사합니다. 이 과정을 통과한 설정만 샘플링합니다. 기능 커버리지의 100%는 이 12개 구간을 방문했다는 뜻이며 전체 설계의 완전 검증을 의미하지 않습니다.

042교시 ① · 전체 TB 코드 (60~90분)

원본 RTL을 수정하지 않고 공개 포트만 연결합니다. 각 설정은 음의 에지에 구동하며, pending의 해제까지 최대 24클록 기다립니다. 설정마다 8개의 연속된 클록에서 HIGH 개수를 계산해 PWM 출력까지 자동 판정합니다.

tb/ch12/tb_pwm_coverage.sv · SystemVerilog · 전체 코드 · 실행 NOT_RUN
`timescale 1ns/1ps
// 제12장: 원본 pwm_core의 설정 조합을 기능 커버리지로 측정한다.
// 기능 커버리지는 '입력 조합을 실제로 적용했는가'를 기록한다.
// PWM의 정확한 파형은 8클록 HIGH 개수 검사로 별도 판정한다.
module tb_pwm_coverage;
    logic clk = 0;
    logic resetn = 0;
    logic cfg_apply = 0;
    logic [31:0] cfg_period = 32'd8;
    logic [31:0] cfg_duty = 0;
    logic cfg_enable = 0;
    logic cfg_polarity = 0;
    wire pwm_out, pending, active_enable, active_polarity;
    wire [31:0] active_period, active_duty;
    int checks = 0;

    pwm_core #(.RESET_PERIOD(32'd8)) dut (
        .clk(clk), .resetn(resetn), .cfg_apply(cfg_apply),
        .cfg_period(cfg_period), .cfg_duty(cfg_duty),
        .cfg_enable(cfg_enable), .cfg_polarity(cfg_polarity),
        .pwm_out(pwm_out), .pending(pending),
        .active_period(active_period), .active_duty(active_duty),
        .active_enable(active_enable), .active_polarity(active_polarity)
    );
    always #5 clk = ~clk;

    // 명시적 sample()을 호출하므로 리셋/설정 대기 구간은 기록하지 않는다.
    covergroup pwm_cfg_cg with function sample(
        int unsigned duty, bit en, bit pol
    );
        option.per_instance = 1;
        cp_duty: coverpoint duty {
            bins zero = {0};
            bins middle = {[1:7]};
            bins full = {8};
            illegal_bins outside = default;
        }
        cp_enable: coverpoint en {
            bins disabled = {0};
            bins enabled = {1};
        }
        cp_polarity: coverpoint pol {
            bins normal = {0};
            bins inverted = {1};
        }
        cx_settings: cross cp_duty, cp_enable, cp_polarity;
    endgroup
    pwm_cfg_cg cov = new();

    task automatic run_case(
        input logic [31:0] duty,
        input logic en, input logic pol
    );
        int waited;
        int highs;
        int expected_highs;
        // 음의 에지에서 입력을 바꿔 양의 에지 샘플과 충돌하지 않는다.
        @(negedge clk);
        cfg_duty = duty;
        cfg_enable = en;
        cfg_polarity = pol;
        cfg_apply = 1;
        @(negedge clk);
        cfg_apply = 0;
        if (pending !== 1'b1)
            $fatal(1, "FAIL pending did not assert");

        // 실제 DUT는 shadow 값을 주기 경계에서 활성화한다.
        waited = 0;
        while (pending !== 1'b0 && waited < 24) begin
            @(negedge clk);
            waited++;
        end
        if (pending !== 1'b0 || active_period !== 32'd8 ||
            active_duty !== duty || active_enable !== en ||
            active_polarity !== pol)
            $fatal(1, "FAIL apply duty=%0d en=%b pol=%b", duty, en, pol);

        // 8개의 연속된 PWM 클록을 관찰하면 정확히 한 주기이다.
        // enable=0이면 polarity와 무관하게 LOW가 유지된다.
        highs = 0;
        for (int i = 0; i < 8; i++) begin
            @(negedge clk);
            if (pwm_out === 1'bx || pwm_out === 1'bz)
                $fatal(1, "FAIL unknown pwm_out");
            if (pwm_out) highs++;
        end
        expected_highs = en ? (pol ? 8 - int'(duty) : int'(duty)) : 0;
        if (highs != expected_highs)
            $fatal(1, "FAIL waveform duty=%0d en=%b pol=%b high=%0d expected=%0d",
                   duty, en, pol, highs, expected_highs);

        // 출력 검사가 끝난 실제 적용 조합만 커버리지에 포함한다.
        cov.sample(duty, en, pol);
        checks++;
        $display("CHECK duty=%0d en=%b pol=%b highs=%0d",
                 duty, en, pol, highs);
    endtask

    initial begin
        #10000;
        $fatal(1, "FAIL GLOBAL_TIMEOUT");
    end

    initial begin
        $dumpfile("ch12_pwm_coverage.vcd");
        $dumpvars(0, tb_pwm_coverage);
        repeat (3) @(negedge clk);
        resetn = 1;
        // 3 듀티 구간 × 2 enable × 2 polarity = 12개 cross bin.
        for (int d = 0; d < 3; d++) begin
            for (int e = 0; e < 2; e++) begin
                for (int p = 0; p < 2; p++) begin
                    case (d)
                        0: run_case(32'd0, bit'(e), bit'(p));
                        1: run_case(32'd4, bit'(e), bit'(p));
                        2: run_case(32'd8, bit'(e), bit'(p));
                    endcase
                end
            end
        end
        if (checks != 12)
            $fatal(1, "FAIL missing test cases");
        if (cov.get_coverage() < 99.99)
            $fatal(1, "FAIL coverage=%0.2f", cov.get_coverage());
        $display("PASS CH12 cases=%0d coverage=%0.2f%%",
                 checks, cov.get_coverage());
        $finish;
    end
endmodule

핵심 코드 풀이

pwm_cfg_cg with function sample(...)은 검사 통과 후 수동 샘플링하는 구조입니다. cx_settings는 세 커버포인트의 조합을 세며, run_case()는 입력 구동 → 설정 적용 확인 → 출력 검사 → 커버리지 기록을 하나의 절차로 묶습니다. highs와 expected_highs의 비교는 커버리지와 독립적인 정답 판정입니다.

052교시 ② · 실행과 예상 출력 (90~105분)

기능 커버리지 구문을 지원하는 xrun 시뮬레이터가 필요합니다. 첫 번째 인자로 기존 pwm_core.v의 실제 파일 경로를 전달합니다. 도구가 없거나 원본 경로가 없으면 스크립트는 NOT_RUN을 표시하고 종료합니다.

tb/ch12/run_ch12.sh · Bash · 전체 코드 · 실행 NOT_RUN
#!/usr/bin/env bash
# 제12장: xrun 기능 커버리지 지원 환경에서 실행.
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
RTL="${1:-}"
if [[ -z "$RTL" || ! -f "$RTL" ]]; then
  echo "NOT_RUN: pwm_core.v 파일 경로를 첫 인자로 지정하세요" >&2
  exit 2
fi
if ! command -v xrun >/dev/null 2>&1; then
  echo "NOT_RUN: xrun 기능 커버리지 시뮬레이터 없음" >&2
  exit 2
fi
RTL="$(realpath "$RTL")"
mkdir -p "$ROOT/out/ch12"
cd "$ROOT/out/ch12"
xrun -64bit -sv -coverage functional -covoverwrite -access +r \
  "$RTL" "$ROOT/tb/ch12/tb_pwm_coverage.sv" -R -l ch12.log

예상 출력 — 실제 실행 결과가 아님

정상 실행 시 마지막 로그 · 예상 출력 · 전체 코드 · 실행 NOT_RUN
CHECK duty=8 en=1 pol=1 highs=0\nPASS CH12 cases=12 coverage=100.00%\n

실제 커버리지 수치는 도구의 커버리지 옵션과 지원 수준에 따라 달라질 수 있습니다. 본 환경에서는 시뮬레이션을 실행하지 않았으므로 이 출력은 관찰 기록이 아닙니다.
